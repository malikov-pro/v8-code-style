# Соединение с виртуальной таблицей

Зависимости отслеживаются и при загрузке проекта, и при позднем старте бандла для уже активных проектов. Повторный start идемпотентен; unload/stop снимают listeners. Поздний запуск проверяется отдельной регрессией с неизменным потребителем; тест импорта не доказывает работу в существующем workspace.

Отмечает каждую разрешённую виртуальную таблицу непосредственно в соединении с любой стороны. Отдельная ВТ и ВТ внутри не соединяемого подзапроса не являются источником внешнего соединения. Включена по умолчанию, MAJOR/CODE_STYLE, без параметров и автоисправления. Вид ВТ разрешается по метаданным, не только имени в тексте. Диапазоны, каналы потребителей и ограничения сертифицируются отдельно; полный движковый differential LS не заявляется.

Обычные ВТ и КритерийОтбора определяются через разрешённый DbViewSelectDef; бухгалтерская Субконто включается по feature extDimensionsView, хотя EDT представляет её как DbViewTableDef. Физические и неразрешённые таблицы пропускаются. Цепочка соединений даёт одно замечание на источник-ВТ, не по одному на каждый JOIN. QL-диапазон включает ссылку и аргументы, без явного или неявного алиаса; native BSL-мост сохраняет только строку литерала.

Проверены циклы исходников BSL и наборов СКД. Изменение периодичности регистра сведений и загрузка его .mdo проверены при неизменном потребителе: lifecycle-listener наблюдает производный dbViewDefs и планирует включённые хабы/делегаты. Он просматривает QL-модели СКД текущего проекта и выбирает потребителей с binding к регистру, включая физического родителя исчезнувшей ВТ. BSL-fallback перепроверяет модули проекта в ограниченной области checks; это не индексный поиск потребителей. Производительность большой конфигурации, межпроектность и изменения других видов поставщиков не сертифицированы.

Отключённые хабы/чеки уважаются для новой работы. При выключении штатного СКД-хаба могут сохраняться СТАРЫЕ маркеры делегатов; их ID/createdAt проверяются отдельно от новых замечаний. Динамические списки, редактор конструктора, расширения, переименование/создание/удаление поставщика, необычный препроцессор/recovery и полный LS differential не сертифицированы. Связанные позиции и custom UI не добавлены.
