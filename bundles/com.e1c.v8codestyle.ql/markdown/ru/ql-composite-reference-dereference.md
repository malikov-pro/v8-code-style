# Разыменование составной ссылки в запросе

Обращение к реквизиту составной ссылки может добавлять неявные соединения
со всеми таблицами её типа. Ограничьте тип через `ВЫРАЗИТЬ`, если запросу
нужен реквизит конкретного объекта.

```sdbl
// Неправильно: Поле имеет несколько ссылочных типов
ВЫБРАТЬ Данные.Поле.Наименование ИЗ Справочник.Данные КАК Данные
// Правильно
ВЫБРАТЬ ВЫРАЗИТЬ(Данные.Поле КАК Справочник.Товары).Наименование
ИЗ Справочник.Данные КАК Данные
```

Проверка использует типы EDT, а не число точек. Широкие группы, включая
`ЛюбаяСсылка`, раскрываются в контексте запроса, одинаковые типы считаются
один раз. Параметр `minReferenceTypes` — минимальное число ссылочных таблиц,
по умолчанию 2; значения ниже 2 трактуются как 2.

Учитываются ссылки на справочники, документы, планы обмена, планы счетов,
планы видов характеристик и расчёта, бизнес-процессы и задачи. Перечисления,
точки маршрута и примитивы не учитываются. Неизвестные типы и ошибочный
синтаксис пропускаются. Ограничение типа через `ВЫРАЗИТЬ` не помечается,
но разыменование внутри его аргумента проверяется.

Это самостоятельная нормативная проверка, не буквальный перенос
`QueryNestedFieldsByDot` LS или АПК_00223/01184/01185: у них другие правила
подсчёта. Быстрого исправления нет — нужный тип выбирает разработчик.
