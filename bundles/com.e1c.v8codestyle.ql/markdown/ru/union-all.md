# ОБЪЕДИНИТЬ без ВСЕ

Отмечает каждое ОБЪЕДИНИТЬ без ВСЕ по контракту pinned LS. Включена по умолчанию, MINOR/CODE_STYLE, без параметров. Автоисправления нет: ВСЕ меняет устранение дублей и требует решения разработчика. Точная позиция QL-ключевого слова и только строка в BSL-мосте — разные гарантии. Неиспытанные источники запросов, расширения и полный движковый differential LS не сертифицированы.
