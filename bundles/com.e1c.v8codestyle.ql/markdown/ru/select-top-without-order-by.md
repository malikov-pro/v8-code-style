# ПЕРВЫЕ без УПОРЯДОЧИТЬ ПО

Pinned LS проверяет ПЕРВЫЕ в частях объединения даже при общей сортировке, иначе — ПЕРВЫЕ без сортировки. ПЕРВЫЕ0/1 исключает ГДЕ либо, вне объединений, skipSelectTopOne=true (дефолт). Для других лимитов ГДЕ не даёт исключения. Включена по умолчанию, MAJOR/CODE_STYLE, без автоисправления. Точный QL-диапазон ПЕРВЫЕ и строка native BSL-моста — разные гарантии; полная движковая эквивалентность LS не сертифицирована.

Лимит сравнивается по записи числа без нормализации: 01 не получает исключение для 1. Диапазон включает ПЕРВЫЕ и число. Сортировка берётся у своего запроса-владельца; сортировка внешнего запроса или другой части пакета не упорядочивает вложенный. Некорректные/нелитеральные лимиты консервативно пропускаются. Границы модели проверены адаптированными регрессиями, а не полной эквивалентностью рекурсивному поиску ORDER в parent LS; необычные вложенные сортировки, препроцессор/recovery не сертифицированы.

Изменения исходника проверены через BSL-литералы и наборы СКД. При изменении только параметра BSL пересчитывается штатно. Для СКД продуктовый слушатель настроек планирует включённые хаб и делегат вместе на контейнерах схем текущего проекта. Исходники/настройки не переписываются, отключённый хаб или чек уважается. Стартового сканирования проектов нет. Динамические списки, смена профиля, переключение enabled самого делегата, межпроектность, GUI-навигация и производительность большой конфигурации не сертифицированы.
