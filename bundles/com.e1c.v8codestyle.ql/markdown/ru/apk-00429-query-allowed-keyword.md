# Использование ключевого слова РАЗРЕШЕННЫЕ в запросах

Проверяет запросы, использующие ключевое слово РАЗРЕШЕННЫЕ. Оно скрывает строки, к которым у пользователя нет прав, что может искажать результат запроса: пользователь видит не все данные, а бизнес-логика рассчитывает на полные данные.

Не используйте РАЗРЕШЕННЫЕ в запросах, которые влияют на расчёты и проведение операций. Если для выполнения операции нужны данные, к которым у пользователя нет доступа — либо предоставьте права чтения, либо прервите операцию с сообщением о недостатке прав. РАЗРЕШЕННЫЕ допустимо, когда скрываемые данные не участвуют в бизнес-процессах (динамические списки, интерактивные отчёты).

Проверка — аудит использования: законность зависит от роли запроса в приложении и статически не доказуема, поэтому каждое использование только помечается. Проверка **выключена по умолчанию** — включите её для аудита проекта.

## Неправильно

```bsl
// Запрос, влияющий на расчёт: данные скрываются и результат искажается.
Запрос = Новый Запрос(
    "ВЫБРАТЬ РАЗРЕШЕННЫЕ
    |   Партии.Номенклатура,
    |   Партии.СтоимостьОстаток
    |ИЗ
    |   РегистрНакопления.ПартииТоваровОрганизаций.Остатки КАК Партии");
```

## Правильно

```bsl
// Если доступ к данным для расчёта отсутствует, операцию нужно прервать.
Если Не ЕстьПраваДляРасчетаСебестоимости Тогда
    ВызватьИсключение НСтр("ru='Недостаточно прав для расчета себестоимости.'");
КонецЕсли;

Запрос = Новый Запрос(
    "ВЫБРАТЬ
    |   Партии.Номенклатура,
    |   Партии.СтоимостьОстаток
    |ИЗ
    |   РегистрНакопления.ПартииТоваровОрганизаций.Остатки КАК Партии");
```
