# Избыточное использование "Ссылка" в запросе

Получение поля `Ссылка` (`Reference`, `Ref`) у ссылочного реквизита заставляет СУБД
соединяться с таблицей-источником без пользы: запрос читает лишнюю таблицу и
возвращает ту же ссылку, которая уже есть.

Путь помечается, когда последний сегмент `Ссылка` избыточен:

- путь, заканчивающийся на `Ссылка`, помечается, если предыдущий сегмент — не
  источник этого запроса: `Таблица.Ссылка` — это сама ссылка;
- `Ссылка` первым сегментом более длинного пути не помечается;
- `Таблица.Ссылка.Реквизит` не помечается, если таблица — табличная часть,
  виртуальная таблица или таблица без разрешённых метаданных: там
  `Таблица.Ссылка` — ссылка владельца;
- `Ссылка` в более поздней позиции с продолжением пути помечается всегда.

Поля вложенных запросов проверяются как отдельный запрос, поля внутри
конструктора таблицы в скобках не проверяются — как в pinned BSL Language
Server. Маркер охватывает весь путь к полю.

## Неправильно

```bsl
ТекстЗапроса = "ВЫБРАТЬ
|   Док.Ссылка.Наименование КАК НаименованиеДокумента
|ИЗ Документ.ЗаказПокупателя КАК Док";
```

## Правильно

```bsl
ТекстЗапроса = "ВЫБРАТЬ
|   Док.Наименование КАК НаименованиеДокумента
|ИЗ Документ.ЗаказПокупателя КАК Док";
```
