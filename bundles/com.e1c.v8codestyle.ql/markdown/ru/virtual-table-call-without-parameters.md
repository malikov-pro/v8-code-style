# Вызов виртуальной таблицы без параметров

При позднем старте бандла сервис подключает уже активные проекты, а не только будущие lifecycle-загрузки. Start идемпотентен, stop/unload снимают listeners. Новый сервис, запущенный после открытия проекта, проверен отдельной provider-only регрессией.

Сохраняет позиции аргументов pinned LS: пустой вызов отмечается; единственный непустой период допустим; при нескольких позициях первая пропускается и требуется непустая последующая. КритерийОтбора требует свой параметр. Бухгалтерская Субконто исключена. Используются разрешённые виды метаданных, не только имена таблиц. Включена по умолчанию, MAJOR/ERROR, без параметров и автоисправления. Каналы, диапазоны и ограничения сертифицируются отдельно; полный differential LS не заявляется.

Пустой аргумент EDT представляет как QuerySchemaExpression с EmptyExpression. Проверяются обычные и DCS-expression; одни комментарии не делают аргумент непустым. Исключение единственной позиции периода сохраняет буквальное поведение pinned LS и не ужесточается. Критерий определяется по владельцу метаданных binding. Физические/неразрешённые таблицы, включая DbViewTableDef Субконто, не проверяются. QL-диапазон включает ссылку/аргументы без алиаса; BSL получает только строковую позицию native-моста.

Раздельно проверены изменения аргументов BSL/СКД и периодичности поставщика-регистра сведений, включая внешнюю загрузку .mdo при неизменных bytes/stamp потребителя. Lifecycle-listener наблюдает производный dbViewDefs. Кандидаты СКД разбираются и фильтруются по binding регистра/родителя; для BSL выполняется ограниченная областью checks перепроверка модулей проекта. Нет переписывания исходника/настроек, кеша недоказанного false или угадывания поставщика по имени. Стоимость разбора/сканирования на большой конфигурации не измерена.

Отключённые чеки/хабы уважаются, но штатный СКД-хаб может сохранять старые delegated markers после отключения. Отсутствие новых запусков не доказывается только прежним count. Динамические списки, UI конструктора, расширения, межпроектность, изменения других поставщиков, rename/create/delete и препроцессор/recovery не сертифицированы. Адаптированный корпус не равен исполнению LS-движка.
