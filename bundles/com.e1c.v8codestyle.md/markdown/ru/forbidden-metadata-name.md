# Запрещённые имена метаданных

Проверяются 64 русских и английских имени из закреплённой версии правила
`ForbiddenMetadataName` BSL Language Server. Сравнивается **полное имя** без
учёта регистра, не подстрока и не произвольный список ключевых слов SQL.

## Охват

16 видов объектов: четыре регистра, бизнес-процесс, справочник, три плана,
константа, документ, журнал документов, перечисление, план обмена, критерий
отбора и задача. Поля хранения: реквизиты, измерения, ресурсы, признаки учёта,
графы журнала документов, табличные части и их реквизиты. Формы, команды,
значения перечислений и стандартные реквизиты исключены.

Включена по умолчанию, ERROR / CRITICAL, без параметров и быстрых исправлений.
Первоначальный охват — базовые конфигурации; проекты расширений исключены.
Ограничения поддержки поставщика сохраняются. Замечание привязано к имени
метаданных и не требует BSL-текста; LS использует диапазон BSL-модуля.
Если имя также совпадает с владельцем, другое правило может дать второе
замечание. Автоматического переименования и отключения других проверок нет.
