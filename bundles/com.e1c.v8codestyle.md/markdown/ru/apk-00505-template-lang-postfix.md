# Постфикс кода основного языка в имени двоичного макета или HTML-макета

Двоичный макет или HTML-макет, подлежащий переводу, должен быть помечен
постфиксом в имени: подчёркивание и код основного языка конфигурации,
например **_ru**. При добавлении языков интерфейса для такого макета
создаётся копия на каждый язык, а не переводится его содержимое. В коде
макет получают с постфиксом текущего языка.

Проверяются двоичные макеты и HTML-макеты (общие макеты и макеты прикладных
объектов). Табличные, текстовые и остальные типы макетов переводятся без
подготовительных действий и не проверяются.

В отличие от алгоритма АПК, проверяющего только HTML-макеты с изображениями,
эта проверка сообщает обо всех HTML-макетах без постфикса языка.

## Неправильно

Макет печатной формы в формате OpenOffice Writer без постфикса:

```xml
<templates uuid="...">
  <name>ПФ_ODT_СчетНаОплату</name>
  <templateType>BinaryData</templateType>
</templates>
```

## Правильно

```xml
<templates uuid="...">
  <name>ПФ_ODT_СчетНаОплату_ru</name>
  <templateType>BinaryData</templateType>
</templates>
```

## См. также

- [Стандарт 766. Требования по локализации макетов](https://its.1c.ru/db/v8std#content:766:hdoc)
- Перенос проверки АПК `АПК_00505`.
- Если основной язык конфигурации не задан, макеты не проверяются.
- Проверка не распространяется на заимствованные объекты расширений.
