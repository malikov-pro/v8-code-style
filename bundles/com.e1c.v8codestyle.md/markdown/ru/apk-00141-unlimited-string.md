# Реквизит строкового типа неограниченной длины

Строки неограниченной длины допустимы только в отдельных случаях:

- в реквизит помещается пользовательский текст, объём которого может быть
  значительным (как правило, многострочные поля на форме) — например,
  «Дополнительное описание», «Комментарий»;
- в реквизите хранится техническая информация, которая генерируется
  программами и обычно не предназначена для чтения пользователем —
  например, XML-документы, заголовки почтовых сообщений.

Если максимально возможную длину строки можно оценить, использование строки
неограниченной длины не оправдано: ограничьте длину реквизита. Также у поля
ввода на форме для такого реквизита должен быть включён многострочный режим.

Проверка — **ручной аудит**: решение об оправданности неограниченной длины
принимает разработчик, поэтому проверка по умолчанию **выключена**
(включается в настройках проверок).

## Неправильно

Реквизит `Артикул` типа `Строка` (неограниченная длина):

```xml
<type>
  <types>String</types>
  <stringQualifiers/>
</type>
```

## Правильно

```xml
<type>
  <types>String</types>
  <stringQualifiers>
    <length>25</length>
  </stringQualifiers>
</type>
```

## См. также

- Перенос проверки АПК `АПК_00141`.
- Проверка не распространяется на заимствованные объекты расширений
  и на реквизиты, тип которых задан определяемым типом. Реквизиты форм
  не проверяются (канал метаданных).
