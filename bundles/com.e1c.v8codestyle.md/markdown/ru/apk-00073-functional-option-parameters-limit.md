# Ограничения на использование параметров функциональных опций

В конфигурации рекомендуется создавать не более **10 параметров функциональных
опций**. Ровно 10 допустимо; при превышении выдаётся одно замечание на
конфигурацию. Считаются все созданные параметры, в том числе неиспользуемые.
Объединяйте параметры одной смысловой нагрузки.

Перенесён инвариант подсчёта АПК `АПК_00073`. Источник не задаёт
формализованного сообщения, поэтому здесь сформулировано новое. Быстрого
исправления нет: объединение параметров меняет поведение приложения.
Расширения не проверяются: их локальное количество не равно общему
количеству параметров основной конфигурации.
