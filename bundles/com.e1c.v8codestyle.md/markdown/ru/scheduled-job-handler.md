# Контракт обработчика регламентного задания

Остатки: флаг Сервер у назначенного общего модуля, параметры предопределённого задания и повторные назначения одного обработчика. Штатные проверки отсутствующего/неэкспортного метода и существующая проверка полностью пустого метода не дублируются. Функции допустимы; параметры обработчика по умолчанию тоже считаются параметрами. Включена по умолчанию, CRITICAL/ERROR, без параметров и автоисправления. Полная эквивалентность LS и reference-index семантика пустоты тела не сертифицированы.

Общий модуль разрешается по квалифицированной metadata-ссылке в текущей BM-транзакции. Формальные параметры читаются из исходного BSL-модуля; пустой экспортный контекст не считается доказательством нулевого числа параметров. Для non-server поставщика выдаётся только замечание о Сервер. Отсутствующий модуль пропускается. Отсутствующий/приватный метод может участвовать в дублях или независимом замечании о параметрах согласно порядку pinned LS; ошибку отсутствия/Экспорт оставляем EDT.

Ключ дублей использует разрешённое имя модуля и регистрозависимое имя метода, как LS. Один маркер дубля относится к methodName первого задания по имени; замечания о параметрах независимы. Use=false не исключает задание. При BM-изменении назначения пересчитываются старая и новая группы. При файловой синхронизации приходит производный schedule без старого обработчика, поэтому пересчитывается набор регламентных заданий текущего проекта. Каждый check просматривает задания; такой пересчёт может иметь квадратичную стоимость, производительность большой конфигурации не сертифицирована. Server/contextDef поставщика пересчитывает ссылающиеся задания. Файловое изменение сигнатуры при прежнем минимальном числе аргументов проверено регрессией.

Расширения, межпроектный scope, пересчёт при создании/удалении/переименовании и варианты препроцессора не сертифицированы. Основная позиция — свойство methodName метаданных, не проектный/сеансовый якорь LS. Связанные позиции и эмуляция ReferenceIndex для пустоты тела не добавлены.
