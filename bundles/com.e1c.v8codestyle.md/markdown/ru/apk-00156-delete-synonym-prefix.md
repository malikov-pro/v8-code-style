# Префикс «Удалить» в имени устаревшего объекта не согласован с префиксом «(не используется)» в синониме

Устаревший объект метаданных, который пока нельзя удалить из конфигурации,
переименовывается с префикса **Удалить** в имени, а в его синоним добавляется
префикс **(не используется)**. Например, реквизит `ОсновнойДоговор` становится
`УдалитьОсновнойДоговор` с синонимом «(не используется) Основной договор».

Префиксы согласованы: если имя объекта начинается с **Удалить** (в любом
регистре), то синоним должен начинаться с **(не используется)** — и наоборот.
Префикс «(не используется)» в синониме означает, что объект устарел и перенос
данных в новые структуры завершён, поэтому имя также должно быть помечено
префиксом «Удалить».

Объект с пустым синонимом не проверяется.

## Неправильно

Реквизит `УдалитьОсновнойДоговор` имеет синоним «Основной договор»
(отсутствует префикс синонима):

```xml
<attributes uuid="...">
  <name>УдалитьОсновнойДоговор</name>
  <synonym>
    <key>ru</key>
    <value>Основной договор</value>
  </synonym>
</attributes>
```

## Правильно

```xml
<attributes uuid="...">
  <name>УдалитьОсновнойДоговор</name>
  <synonym>
    <key>ru</key>
    <value>(не используется) Основной договор</value>
  </synonym>
</attributes>
```
