# У реквизита строкового типа допустимая длина фиксированная

Для реквизитов строкового типа следует использовать переменную длину строки
(свойство **Допустимая длина** = **Переменная**) и указывать максимально
допустимую длину строки.

Свойство **Допустимая длина** может принимать значение **Фиксированная**
только в тех случаях, когда при манипуляции этими данными действительно
необходимо иметь гарантию, что строка имеет определенную длину, даже
несмотря на наличие концевых пробелов. Фиксированные строки занимают
лишнее место в базе данных и порождают концевые пробелы при сравнении
и поиске.

## Неправильно

Реквизит `Артикул` типа `Строка(10, Фиксированная)`:

```xml
<type>
  <types>String</types>
  <stringQualifiers>
    <length>10</length>
    <fixed>true</fixed>
  </stringQualifiers>
</type>
```

## Правильно

```xml
<type>
  <types>String</types>
  <stringQualifiers>
    <length>10</length>
  </stringQualifiers>
</type>
```

## См. также

- Перенос проверки АПК `АПК_00139`.
- Проверка не распространяется на заимствованные объекты расширений
  и на реквизиты, тип которых задан определяемым типом.
