# Расширенное представление списка совпадает с представлением списка

**Расширенное представление списка** задаётся полным названием списка
объектов. Оно показывается в заголовках и подсказках форм списков вместо
представления списка, поэтому имеет смысл, только когда информативнее
представления списка (или синонима, если представление списка не заполнено).
Заполнять его тем же текстом, что и представление списка, бессмысленно:
в этом случае его заполнять не нужно вовсе.

Например, синоним — «Номенклатура», расширенное представление списка —
«Номенклатура (товары и услуги)»: расширенное представление добавляет
информацию. Если же в обоих свойствах «Номенклатура», расширенное
представление не добавляет ничего.

Сравниваются все языки, для которых заданы оба представления, без учёта
регистра и пробелов по краям. На объект создаётся одно замечание.

Проверяются объекты метаданных верхнего уровня, у которых есть представления
списка: справочники, документы и другие объекты БД, регистры сведений,
накопления, бухгалтерские и расчёта, перечисления, журналы документов
и критерии отбора. Случай, когда представление списка не заполнено,
а расширенное представление совпадает с синонимом, не проверяется
(отдельное правило АПК 1216).

## Неправильно

```xml
<listPresentation>
  <key>ru</key>
  <value>Номенклатура</value>
</listPresentation>
<extendedListPresentation>
  <key>ru</key>
  <value>номенклатура</value>
</extendedListPresentation>
```

## Правильно

```xml
<listPresentation>
  <key>ru</key>
  <value>Номенклатура</value>
</listPresentation>
<extendedListPresentation>
  <key>ru</key>
  <value>Номенклатура (товары и услуги)</value>
</extendedListPresentation>
```

Либо расширенное представление списка не заполняется вовсе.
