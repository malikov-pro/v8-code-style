# Кодировка, отличная от utf-8, в текстовом или HTML-макете

Содержимое текстового макета и HTML-макета должно быть в кодировке utf-8.
Сообщается о макете, в содержимом которого объявлена кодировка атрибутом
`encoding=` или `charset=` (регистронезависимо) со значением, отличным
от utf-8.

Проверяются текстовые макеты и HTML-макеты (общие макеты и макеты прикладных
объектов). Макеты с пустым или недоступным из модели проекта содержимым
не проверяются.

## Неправильно

Текстовый макет с кодировкой windows-1251:

```xml
<?xml version="1.0" encoding="windows-1251"?>
```

HTML-макет с meta-тегом, объявляющим windows-1251:

```html
<meta charset="windows-1251">
```

## Правильно

```xml
<?xml version="1.0" encoding="utf-8"?>
```

```html
<meta charset="utf-8">
```
