# Буква «ё» в имени, синониме или комментарии объекта метаданных

В именах, синонимах и комментариях объектов метаданных не допускается
использовать букву **ё** (в любом регистре, **ё**/**Ё**) — заменяйте её
на **е**. Синоним проверяется на всех языках конфигурации.

Замечание ставится на сам объект метаданных, в сообщении указывается,
в каком свойстве (имя, синоним или комментарий) найдена буква.

## Неправильно

```xml
<name>ElkaCatalog</name>
<synonym>
  <key>ru</key>
  <value>Справочник «Ёлка»</value>
</synonym>
<comment>Хранит список ёлок</comment>
```

## Правильно

```xml
<name>ElkaCatalog</name>
<synonym>
  <key>ru</key>
  <value>Справочник «Елка»</value>
</synonym>
<comment>Хранит список елок</comment>
```

## См. также

- [Стандарт 598. Отказ от использования буквы «ё» в именах объектов метаданных](https://its.1c.ru/db/v8std#content:598:hdoc)
- Перенос проверки АПК `АПК_00126`.
- Для буквы «ё» в текстах модулей (код, строковые литералы, комментарии)
  предназначена проверка `apk-00260-no-yo-letter`.
- Проверка не распространяется на заимствованные объекты расширений.
- Примечание: соседняя проверка `mdo-ru-name-unallowed-letter` охватывает
  только объекты верхнего уровня (строчную «ё», синоним на русском); эта
  проверка следует алгоритму АПК и охватывает все объекты метаданных
  и оба регистра.
