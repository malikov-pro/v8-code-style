# Подсказка реквизита совпадает с синонимом

Подсказка задаётся для тех реквизитов, которые выводятся пользователю
в виде элементов интерфейса и требуют пояснения, расшифровки и донесения
до пользователя подробного описания их назначения. Подсказка, повторяющая
синоним реквизита, не несёт дополнительной информации — заполните подсказку
осмысленным пояснением назначения реквизита или оставьте её пустой.

Как и в исходном алгоритме АПК:

- реквизиты с пустой подсказкой не проверяются;
- из стандартных реквизитов проверяются только **Код**, **Наименование**,
  **Родитель**, **Владелец** и **Период**, причём **Период**
  непериодического регистра сведений не проверяется;
- проверяются только реквизиты объектов, включённых хотя бы в одну
  подсистему с флагом **Включать в командный интерфейс**; для реквизита
  табличной части владельцем считается объект — владелец табличной части.

## Неправильно

Реквизит `Цена`, у которого подсказка совпадает с синонимом:

```xml
<attributes uuid="...">
  <name>Price</name>
  <synonym>
    <key>en</key>
    <value>Price</value>
  </synonym>
  <toolTip>
    <key>en</key>
    <value>Price</value>
  </toolTip>
  ...
</attributes>
```

## Правильно

Подсказка поясняет назначение реквизита:

```xml
<attributes uuid="...">
  <name>Price</name>
  <synonym>
    <key>en</key>
    <value>Price</value>
  </synonym>
  <toolTip>
    <key>en</key>
    <value>Sale price per unit, excluding VAT</value>
  </toolTip>
  ...
</attributes>
```

## См. также

- Проверка не распространяется на заимствованные объекты расширений.
