# Не заполнена всплывающая подсказка

Чтобы пояснить назначение элемента управления пользователю, выводимому
в интерфейсе реквизиту назначается всплывающая подсказка. Заполнение
подсказки обязательно (стандарт 506): подсказка показывается при наведении
на поле формы, связанное с реквизитом, и помогает понять назначение
реквизита без открытия справки.

О причине сообщается для реквизита, у которого заполнен синоним (то есть
реквизит назван для пользователя), но не заполнена всплывающая подсказка.

Реализована формализуемая часть стандарта — как в родственной проверке
правила АПК 00134 (подсказка совпадает с синонимом):

- проверяются только реквизиты объектов, включённых хотя бы в одну
  подсистему с флагом «Включать в командный интерфейс»; для реквизита
  табличной части объектом-владельцем считается объект табличной части;
- реквизит без синонима не проверяется;
- из стандартных реквизитов проверяются только Код, Наименование, Родитель,
  Владелец и Период, причём «Период» непериодического регистра сведений
  не проверяется.

Проверяются реквизиты объектов, реквизиты табличных частей, измерения
и ресурсы регистров, а также перечисленные стандартные реквизиты. Проверка
не распространяется на заимствованные объекты расширений. Ограничение длины
подсказки в 8 слов здесь не проверяется (правило АПК 1238 и подсказки
в шапках колонок табличных полей — вне области этой проверки).

## Неправильно

Реквизит `Курс` имеет синоним, но подсказка не заполнена:

```xml
<attributes uuid="...">
  <name>Курс</name>
  <synonym>
    <key>ru</key>
    <value>Курс валюты</value>
  </synonym>
</attributes>
```

## Правильно

```xml
<attributes uuid="...">
  <name>Курс</name>
  <synonym>
    <key>ru</key>
    <value>Курс валюты</value>
  </synonym>
  <toolTip>
    <key>ru</key>
    <value>Официальный курс валюты</value>
  </toolTip>
</attributes>
```
