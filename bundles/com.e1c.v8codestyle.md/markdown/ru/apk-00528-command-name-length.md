# Длина названия команды больше 38 символов

Чтобы при стандартном разрешении экрана не возникало полос прокрутки,
название (синоним) команды не должно превышать 38 символов, а лучше —
умещаться в 30.

Как и в исходном алгоритме АПК:

- проверяются только команды (объектов конфигурации) и общие команды,
  остальные объекты, отображаемые в командном интерфейсе, не проверяются;
- если синоним пуст, проверяется имя команды;
- команды, группа которых относится к группе формы, не проверяются;
- проверяются только команды, доступные в командном интерфейсе: команда
  (для команды объекта — объект-владелец) входит в подсистему, у которой
  сама подсистема и все её родительские подсистемы до корня имеют
  включённый флаг **Включать в командный интерфейс**.

В сообщении указывается раздел команды — синоним корневой подсистемы.

## Неправильно

Команда с синонимом длиннее 38 символов:

```xml
<commands uuid="...">
  <name>LongCommand</name>
  <synonym>
    <key>en</key>
    <value>Проведение документов по всем подразделениям организации</value>
  </synonym>
  <group>NavigationPanelOrdinary</group>
  ...
</commands>
```

## Правильно

Синоним укладывается в 30—38 символов:

```xml
<commands uuid="...">
  <name>LongCommand</name>
  <synonym>
    <key>en</key>
    <value>Провести документы</value>
  </synonym>
  <group>NavigationPanelOrdinary</group>
  ...
</commands>
```

## См. также

- Перенос проверки АПК `АПК_00528`.
- Проверка не распространяется на заимствованные объекты расширений.
- Максимальная длина — параметр проверки (по умолчанию 38 символов).
