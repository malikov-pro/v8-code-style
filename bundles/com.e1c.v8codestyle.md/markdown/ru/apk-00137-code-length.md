# Длина кода (номера) объектов конфигурации

Длины кодов (номеров) объектов конфигурации задаются в зависимости от их прикладного смысла.

- Если необходимость в кодировании (нумерации) для объекта отсутствует, длина кода (номера) устанавливается нулевой.
- При разработке типовых конфигураций рекомендуемыми (но не обязательными) являются длины кодов (номеров): 3, 5, 9, 11.
- В длине номера необходимо учитывать длину префиксов нумерации: префикс информационной базы, префикс организации и т.п. Если в конфигурации используется подсистема **Префиксация объектов** из **Библиотеки стандартных подсистем**, совокупную длину (с учетом префикса) номеров документов и кодов справочников рекомендуется устанавливать не менее 11 символов (11, 13, 15, …).

## Неправильно

Справочник **Пользователи** хранит в коде краткое имя пользователя, но длина кода оставлена равной 9 вместо прикладной длины.

## Правильно

Справочник **Пользователи**: длина кода достаточна для краткого имени. Справочник **Номенклатура**: длина кода 9 (или 11 с учетом префиксов).
