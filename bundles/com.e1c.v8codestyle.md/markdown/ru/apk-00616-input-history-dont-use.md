# Свойство «История выбора при вводе» не равно «Не использовать»

Свойство **«История выбора при вводе»** объекта метаданных должно быть в значении **«Не использовать»**:

- у всех **документов** — безусловно: повторный выбор одного из 5 ранее выбранных значений для документов маловероятен;
- у **справочников** и **документов**, в модуле менеджера которых переопределён обработчик **«ОбработкаПолученияДанныхВыбора»**: условия обработчика не учитываются механизмом формирования истории выбора, и пользователь может выбрать значение, которое иначе выбрать нельзя.

История выбора хранится на диске и постоянно пополняется независимо от того, нужна ли она пользователю. Не заданное в проекте значение приравнивается к «Авто» и тоже помечается: единственное допустимое значение — «Не использовать». Одно замечание на объект. Объекты, заимствованные в расширения, не проверяются.

## Неправильно

Свойство документа: **«История выбора при вводе»** = `Авто`.

## Правильно

Свойство документа: **«История выбора при вводе»** = `Не использовать`.
