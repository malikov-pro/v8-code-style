# Расширенное представление объекта совпадает с представлением объекта

**Расширенное представление объекта** (для регистра — расширенное
представление записи) задаётся полным названием объекта в единственном числе.
Оно показывается в заголовках и подсказках форм объектов вместо представления
объекта, поэтому имеет смысл, только когда информативнее представления
объекта (или синонима, если представление объекта не заполнено). Заполнять
его тем же текстом, что и представление объекта, бессмысленно: в этом случае
его заполнять не нужно вовсе.

Например, представление объекта — «Реализация», расширенное представление
объекта — «Реализация товаров и услуг»: расширенное представление добавляет
информацию. Если же в обоих свойствах «Реализация», расширенное представление
не добавляет ничего.

Сравниваются все языки, для которых заданы оба представления, без учёта
регистра и пробелов по краям. На объект создаётся одно замечание.

Проверяются объекты БД верхнего уровня (справочники, документы и др.)
и регистры сведений. У регистров накопления, бухгалтерских и расчёта
в модели метаданных нет представлений записи. Случай, когда представление
объекта не заполнено, а расширенное представление совпадает с синонимом,
не проверяется (отдельное правило АПК 1213).

## Неправильно

```xml
<objectPresentation>
  <key>ru</key>
  <value>Реализация</value>
</objectPresentation>
<extendedObjectPresentation>
  <key>ru</key>
  <value>реализация</value>
</extendedObjectPresentation>
```

## Правильно

```xml
<objectPresentation>
  <key>ru</key>
  <value>Реализация</value>
</objectPresentation>
<extendedObjectPresentation>
  <key>ru</key>
  <value>Реализация товаров и услуг</value>
</extendedObjectPresentation>
```

Либо расширенное представление объекта не заполняется вовсе.

## См. также

- [Стандарт 468. Пользовательские представления объектов](https://its.1c.ru/db/v8std#content:468:hdoc:3)
- Перенос правила АПК `АПК_1211` ([апстрим-issue #722](https://github.com/1C-Company/v8-code-style/issues/722)).
- Проверка не распространяется на заимствованные объекты расширений.
