# Имя поля метаданных совпадает с именем владельца

Имя поля хранения не должно совпадать с именем своего объекта метаданных.
Реквизит табличной части сравнивается **со своей частью**, а не с верхним
объектом. Имя самой части с верхним объектом не сравнивается: это фактический
алгоритм закреплённой версии LS, несмотря на более широкий пример документации.

## Охват

12 видов: четыре регистра, бизнес-процесс, справочник, три плана, документ,
план обмена и задача. Учитываются реквизиты, измерения, ресурсы, признаки
учёта плана счетов. Конфликты соседних имён, стандартные реквизиты, формы
и команды не относятся к этому правилу.

Сравнение без учёта регистра. Включена по умолчанию, ERROR / CRITICAL,
без параметров. Первоначально проверяются базовые конфигурации; проекты
расширений исключены. Ограничения поддержки поставщика сохраняются.
Маркер на имени поля не зависит от BSL-текста, в отличие от доставки LS.
Запрещённое имя независимо может дать второе замечание другого правила.
Автоматического переименования и отключения проверок нет.
