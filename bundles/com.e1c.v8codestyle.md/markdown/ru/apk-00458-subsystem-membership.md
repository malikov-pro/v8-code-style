# Объект не входит ни в одну подсистему

Каждый объект конфигурации должен входить хотя бы в одну подсистему дерева
подсистем конфигурации (включая вложенные), чтобы иметь место в разделах
конфигурации. Объект, не входящий ни в одну подсистему, трудно найти
в приложении, и обычно это признак незавершённой конфигурации: объект либо
не используется и его следует удалить, либо состав подсистем неполон.

Как и в исходном алгоритме АПК, заимствованные объекты расширений
не проверяются: допустимо, что они не принадлежат ни одной подсистеме
расширения.

Служебные объекты, которые не могут входить в состав подсистем, не
проверяются: подсистемы, языки, подписки на события, общие картинки, группы
команд, общие реквизиты, определяемые типы, стили, функциональные опции,
сеансовые параметры, хранилища настроек, XDTO-пакеты, роли, регламентные
задания, нумераторы документов, сервисы интеграции, Web-сокет клиенты
и т.п.

## Неправильно

Справочник не входит в состав ни одной подсистемы:

```xml
<mdclass:Catalog uuid="...">
  <name>LonelyCatalog</name>
  ...
</mdclass:Catalog>
```

## Правильно

Справочник включён в состав подсистемы:

```xml
<mdclass:Subsystem uuid="...">
  <name>Ci</name>
  <includeInCommandInterface>true</includeInCommandInterface>
  <content>Catalog.InSubsystemCatalog</content>
  ...
</mdclass:Subsystem>
```
