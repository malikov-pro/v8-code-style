# Контракт обработчика HTTP-сервиса

Назначенный метод должен существовать в модуле своего HTTP-сервиса и иметь ровно один формальный параметр. Пустое назначение уже проверяет EDT, замечание не дублируется. Вид процедура/функция, Экспорт и тип возврата не ограничены pinned LS. Включена по умолчанию, CRITICAL/ERROR, без параметров, автоисправления и связанных позиций. Расширения, внешние владельцы и полная движковая эквивалентность LS не сертифицированы.

Необязательный параметр тоже считается: один допустим, ноль или два — нет. Имена сравниваются без учёта регистра только внутри фактического модуля-владельца; метод другого сервиса или общего модуля не подходит. Отсутствующий/неразрешённый исходный модуль и неоднозначные объявления пропускаются. Назначение из одних пробелов консервативно считается пустым; буквальная эквивалентность LS для некорректных метаданных не заявляется.

Каждое неверное назначение получает маркер на вложенном свойстве HTTP Method.handler, а не диапазоне модуля/подпрограммы LS. Изменение только исходника пересчитывает владельца через ModuleContextDefIndex.contextDef, включая неэкспортные обработчики. BM- и файловые изменения назначения проверены отдельно. Препроцессор/recovery, удаление/повторное создание файла модуля и владельцы расширений не сертифицированы. Live count/message не доказывают GUI-навигацию карточки.
