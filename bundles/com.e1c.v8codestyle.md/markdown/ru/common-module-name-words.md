# Нерекомендуемые слова в имени общего модуля

Имя общего модуля должно описывать его назначение. Не используйте общие слова
`Процедуры`, `Функции`, `Обработчики`, `Модуль`, `Функциональность` и их
английские эквиваленты.

## Параметры

`words` — регулярное выражение для поиска **подстроки** без учёта регистра.
По умолчанию: `процедуры|procedures|функции|functions|обработчики|handlers|модуль|module|функциональность|functionality`.
Пустое выражение совпадает с любым именем. Если выражение неверно, проверка
записывает WARNING в журнал и пропускается. Остальные проверки продолжают работать.

## Охват и совместимость

Включена по умолчанию, CODE_STYLE / TRIVIAL. Замечание привязано к имени
метаданных, в том числе при отсутствии BSL-текста. Флаги общего модуля
не влияют на результат. На первом этапе проверяются только базовые
конфигурации; проекты расширений исключены. Ограничения поддержки поставщика сохраняются.

Алгоритм поиска имени соответствует `CommonModuleNameWords` BSL Language Server.
В отличие от доставки LS, MD-проверка не требует непустого диапазона BSL-модуля.
Обработка неверного regex также отличается: WARNING и пропуск проверки.
Другие правила имён могут выдать свои замечания. Автоматического переименования
и отключения других проверок нет.
