# String attribute has unlimited length

Unlimited length strings are allowed only in separate cases:

- the attribute stores a user text of potentially significant volume
  (usually multiline form fields) — for example, "Additional description",
  "Comment";
- the attribute stores technical information generated by programs and
  usually not intended to be read by users — for example, XML documents,
  mail message headers.

If the maximum possible length of the string can be estimated, the
unlimited length is not justified: limit the attribute length. Also the
input field on the form for such an attribute should have the multiline
mode enabled.

The check is a **manual audit**: the developer decides whether the
unlimited length is justified, so the check is **disabled by default**
(enable it in the check settings).

## Noncompliant Code Example

The `ArticleNumber` attribute of unlimited `String` type:

```xml
<type>
  <types>String</types>
  <stringQualifiers/>
</type>
```

## Compliant Solution

```xml
<type>
  <types>String</types>
  <stringQualifiers>
    <length>25</length>
  </stringQualifiers>
</type>
```
