# Конкретное значение цвета в элементах формы

Для изменения оформления используйте элементы стиля, а не задавайте конкретные значения цвета непосредственно в элементах управления. Это требуется, чтобы аналогичные элементы управления выглядели одинаково во всех формах, где они встречаются (статья 667 стандарта).

Проверка помечает каждое свойство цвета (цвет текста и цвет фона, включая разновидности: цвет заголовка, подвала, нескольких значений, цвет фона заголовка свернутой группы), которому в элементе формы или его расширении (ext info) присвоено конкретное значение цвета (RGB):

- цвет текста/фона заголовка элемента, цвет текста/фона кнопки, цвет текста/фона подвала поля, цвет текста/фона таблицы, цвет текста декорации;
- цвета текста/фона в расширениях полей ввода, надписи, флажка, картинки, переключателя, текстового и форматированного документа;
- цвет фона групп (обычной, страницы, всплывающей), цвет фона заголовка свернутой группы и цвет фона заголовка колонок;
- цвета текста/фона дополнений таблиц (строка поиска, состояние просмотра, управление поиском).

Ссылка на цвет стиля (`style:...`), веб-цвет (`web:...`), цвет палитры и «авто» не помечаются. Цвета границ, цвет картинки и цвет кнопки дополнения-состояния не проверяются. Базовые формы расширений (заимствованные из основной конфигурации без собственных изменений) не проверяются.

## Неправильно

Элементы формы с конкретными значениями цвета в XML формы:

```xml
<items xsi:type="form:Button">
  <name>BadButton</name>
  ...
  <textColor>#FF0000</textColor>
</items>
<items xsi:type="form:FormField">
  <name>BadField</name>
  ...
  <extInfo xsi:type="form:InputFieldExtInfo">
    <backColor>#00FF00</backColor>
  </extInfo>
</items>
```

## Правильно

Используйте ссылку на цвет стиля:

```xml
<items xsi:type="form:Button">
  <name>GoodButton</name>
  ...
  <textColor>style:ButtonTextColor</textColor>
</items>
```
