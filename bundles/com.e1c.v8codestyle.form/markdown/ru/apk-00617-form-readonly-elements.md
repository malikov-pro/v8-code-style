# Свойства поля формы для объектов с отключённой историей выбора при вводе

После отключения истории выбора при вводе в свойствах объекта метаданных (`История выбора при вводе` = `Не использовать`) во всех ссылающихся на него полях ввода форм следует установить свойства:

- `Кнопка выпадающего списка` — `Нет`;
- `Кнопка выбора` — `Да`;
- `Отображение кнопки выбора` — `В поле ввода`.

Иначе перед началом выбора пользователь попадает в меню недавних значений, где каждый раз приходится нажимать `Показать все`.

Значение, не заданное явно, трактуется как значение по умолчанию (`авто`): кнопка выпадающего списка показывается, отображение кнопки выбора не `В поле ввода` — такое поле помечается.

Не помечаются:

- поля с режимом выбора из списка и заполненным в метаданных списком выбора (список, заполненный программно, статически недетектируем);
- поля, ссылающиеся на объекты метаданных с включённым быстрым выбором;
- поля (а также поля внутри групп и таблиц) с признаком `Только просмотр` — такие элементы недоступны для выбора значения;
- базовые формы расширений.

Признак `Только просмотр` у формы в целом — понятие рантайма, в модели формы не хранится и статически учтён быть не может.

## Noncompliant

Поле ввода, ссылающееся на документ с отключённой историей выбора, свойства оставлены по умолчанию.

## Compliant

То же поле с явно установленными свойствами: кнопка выпадающего списка выключена, кнопка выбора включена, отображение кнопки выбора — `В поле ввода`.
