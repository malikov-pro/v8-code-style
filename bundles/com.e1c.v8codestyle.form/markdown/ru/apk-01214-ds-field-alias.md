# Псевдоним поля запроса динамического списка совпадает с именем класса объектов метаданных

Проверяет, что псевдонимы после ключевых слов `КАК`/`AS` в текстах запросов реквизитов форм с типом «ДинамическийСписок» не называются именами классов объектов метаданных (`Справочник`, `Документ`, `Catalog`, `Document` и т.п.). Такой псевдоним, как правило, не описывает назначение источника или поля в конкретном запросе: псевдонимы должны быть осмысленными и образовываться от терминов предметной области, как имена переменных (например, `ТоварыНаСкладах`).

Ключевое слово ищется текстово в тексте запроса динамического списка; комментарии в тексте запроса не проверяются. Для псевдонимов в текстах запросов в модулях см. родственную проверку `apk-01216-query-field-alias` (bsl-канал).

## Неправильно

Текст запроса реквизита динамического списка:

```sql
ВЫБРАТЬ
	Товары.Ссылка КАК Справочник,
	ЕСТЬNULL(Остатки.КоличествоОстаток, 0) КАК Остаток
ИЗ
	Справочник.Номенклатура КАК Документ
		ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки КАК Справочник
		ПО Товары.Ссылка = Остатки.Номенклатура
```

## Правильно

```sql
ВЫБРАТЬ
	ВсяНоменклатура.Ссылка КАК Товар,
	ЕСТЬNULL(Остатки.КоличествоОстаток, 0) КАК Остаток
ИЗ
	Справочник.Номенклатура КАК ВсяНоменклатура
		ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки КАК ОстаткиНаСкладах
		ПО ВсяНоменклатура.Ссылка = ОстаткиНаСкладах.Номенклатура
```
