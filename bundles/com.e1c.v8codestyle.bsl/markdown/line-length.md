# Line length

Checks that module lines are not longer than the configured maximum (**120 characters** by default, configurable by check parameter). Long lines are hard to read on narrow screens and in code review.

## See

- [BSL Language Server: LineLength](https://1c-syntax.github.io/bsl-language-server/diagnostics/LineLength/)
- Ported from the BSL Language Server diagnostic `LineLength` (simplified).
