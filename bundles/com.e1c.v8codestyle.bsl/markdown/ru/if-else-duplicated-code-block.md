# Повторяющиеся блоки кода в операторе «Если»

Проверяет, что синтаксическая конструкция **Если … Тогда … ИначеЕсли** не содержит повторяющихся блоков кода. Дублирующаяся ветвь — вероятная ошибка копипасты либо признак лишнего условия.

Блоки сравниваются по тексту (без учёта регистра и пробелов). Два пустых блока повторением не считаются.

## Неправильно

```bsl
Если КодОшибки = 1 Тогда
	ЗаписатьВЖурнал(КодОшибки);
	Сообщить(КодОшибки);
ИначеЕсли КодОшибки = 2 Тогда
	ЗаписатьВЖурнал(КодОшибки);
	Сообщить(КодОшибки);
КонецЕсли;
```

## Правильно

```bsl
Если КодОшибки = 1 Тогда
	ЗаписатьВЖурнал(КодОшибки);
	Сообщить(КодОшибки);
ИначеЕсли КодОшибки = 2 Тогда
	ПрерватьРаботу();
КонецЕсли;
```
