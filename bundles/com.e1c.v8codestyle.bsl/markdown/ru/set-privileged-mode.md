# Аудит использования привилегированного режима

Проверка **SECURITY / MAJOR**, выключена по умолчанию, без параметров. Ищет
вызовы `УстановитьПривилегированныйРежим` / `SetPrivilegedMode` по имени,
включая методы произвольного объекта. Совпадение имени не доказывает, что
вызван именно платформенный метод.

Синтаксическое исключение pinned BSL LS действует только для глобального
вызова с одним аргументом, у которого первый member без скобок — `Ложь`.
Унарные операторы LS при этом не учитывает: `Ложь`, `Не Ложь`, `Ложь Или Истина`
и `Ложь = Истина` пропускаются; `(Ложь)` помечается. Member-вызов помечается
даже с `Ложь`. Это паритет синтаксического алгоритма, **не** вычисление
констант и не гарантия выключенного привилегированного режима.

Проверьте необходимость и границы повышения прав. Quick fix отсутствует:
изменение режима может изменить контроль доступа. Отличие от LS — opt-in
вместо включения по умолчанию. Проверки безопасного хранения паролей независимы,
автоматически не выключаются.

Ссылки: [BSL LS](https://v8std.ru/diagnostics/bslls/SetPrivilegedMode/),
[стандарт 485](https://v8std.ru/std/485/), [стандарт 678](https://v8std.ru/std/678/).
