# Явная запись движений документа в обработчике проведения

В обработчике проведения документа (**ОбработкаПроведения**) не следует явно записывать наборы записей регистров методом **Записать**. Запись движений выполняется системой неявно при завершении процедуры проведения. Явная запись при параллельной работе нескольких пользователей может приводить к взаимным блокировкам при проведении документов.

Также фиксируется запись через локальную переменную, которой присвоена коллекция движений (`Движения`), в том числе через цепочки псевдонимов. Записи вне обработчика проведения и закомментированные записи не проверяются.

Исключение: данные, сохраняемые в регистрах, необходимы в последующих алгоритмах, выполняемых до момента выхода из процедуры проведения.

## Неправильно

```bsl
Процедура ОбработкаПроведения(Отказ, Проведение)

	Движения.Продажи.Записать();

	НаборПродаж = Движения.Продажи;
	НаборПродаж.Записать();

КонецПроцедуры
```

## Правильно

```bsl
Процедура ОбработкаПроведения(Отказ, Проведение)

	Движения.Продажи.Записывать = Истина; // запись выполнит система при завершении проведения

КонецПроцедуры
```
