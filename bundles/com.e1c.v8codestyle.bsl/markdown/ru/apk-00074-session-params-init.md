# Инициализацию параметров сеанса следует выполнять в модуле сеанса

Проверяет, что параметрам сеанса (`ПараметрыСеанса.<Имя>`) значения **присваиваются** только в модуле сеанса. Инициализация параметра сеанса в любом другом модуле фиксируется. Чтение параметра сеанса допустимо везде и не фиксируется.

## Неправильно

```bsl
// Общий модуль
Процедура ИнициализироватьПараметрыСеанса() Экспорт
    ПараметрыСеанса.ТекущийПользователь = Неопределено; // присваивание вне модуля сеанса
КонецПроцедуры
```

## Правильно

```bsl
// Модуль сеанса
Процедура ИнициализацияПараметров()
    ПараметрыСеанса.ТекущийПользователь = Неопределено;
КонецПроцедуры
```

Параметры сеанса предназначены для хранения значений определённых типов для каждого клиентского сеанса на время его работы. Инициализация в модуле сеанса гарантирует установку значений при старте сеанса; сами значения рекомендуется использовать в запросах и условиях ограничения доступа к данным текущего сеанса.
