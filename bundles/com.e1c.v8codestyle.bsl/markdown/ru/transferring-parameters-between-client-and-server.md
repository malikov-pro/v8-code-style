# Передача параметров между клиентом и сервером

Включена по умолчанию, CODE_STYLE / MAJOR. Порт диагностики BSL LS
`TransferringParametersBetweenClientAndServer`.

При передаче управления с клиента на сервер и обратно передаются копии
параметров. Клиентский метод, вызывающий серверный, при возврате копирует
обратно на клиент каждый параметр, переданный по ссылке. Если серверный метод
такой параметр не присваивает, обратная копия — лишняя нагрузка: параметру нужен
модификатор `Знач`/`ByValue`.

Проверка сообщает о фактическом параметре вызова, когда одновременно выполнено:

- вызывающий метод исполняется только в клиентском контексте;
- целевой метод исполняется только в серверном контексте;
- у соответствующего формального параметра нет модификатора `Знач`/`ByValue`;
- серверный метод ни разу не присваивает параметр в своём теле.

Порт помечает параметр в точке вызова (фактический параметр), LS помечает
объявление параметра. Анализируются только прямые вызовы с разрешённым целевым
методом.

## Пример

```bsl
&НаКлиенте
Процедура КлиентскийВызов()

	Значение = 1;
	СерверныйМодуль.СервернаяПроцедура(Значение); // замечание: Значение не присваивается на сервере

КонецПроцедуры

&НаСервере
Процедура СервернаяПроцедура(Значение) Экспорт

	Сообщить(Значение);

КонецПроцедуры
```

Исправление — модификатор `Знач`, если сервер значение не возвращает:

```bsl
&НаСервере
Процедура СервернаяПроцедура(Знач Значение) Экспорт
```

## Ограничения

- Поиск присваивания идёт только по телу целевого метода и сравнивает имя
  простого обращения к переменной в левой части `Assignment`. Присваивания
  через свойство или индекс (`Параметр.Поле = ...`, `Параметр[0] = ...`) не
  распознаются, поэтому параметр, изменяемый только так, будет помечен
  (частичный охват).
- Вызовы через переменную и неразрешённые/косвенные вызовы пропускаются молча.
- Контекст метода берётся из `Environmental.environments()`; директивы
  компиляции методов модуля формы используются только как резерв.
- Параметр LS `cachedValueNames` не реализован.
- Проекты расширений (расширения конфигурации) не анализируются.
