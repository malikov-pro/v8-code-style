# Синтаксис локализованной строки функции НСтр

Проверяет, что строковый литерал в вызове функции `НСтр` (`NStr`) соответствует синтаксису локализованной строки (стандарт 761): одна или несколько записей вида «код языка, знак равенства, текст сообщения в одинарных кавычках», разделённых запятыми. Одинарные кавычки внутри текста сообщения удваиваются.

Код языка — 2–5 букв с необязательным регионарным суффиксом, например `ru`, `en`, `zh-CN`.

## Неправильно

```bsl
// Текст сообщения в двойных кавычках вместо одинарных.
Текст = НСтр("ru=""Текст в двойных кавычках""");

// Текст сообщения без кавычек.
Текст = НСтр("ru=Текст");

// Отсутствует код языка.
Текст = НСтр("Просто текст");

// Текст сообщения не закрыт либо одинарная кавычка внутри текста не удвоена.
Текст = НСтр("ru='Незакрытый текст");

// Разделитель без следующей записи языка.
Текст = НСтр("ru='Текст',");
```

## Правильно

```bsl
Текст = НСтр("ru='Текст сообщения'");
Текст = НСтр("ru = 'Текст о ''цитатах'''");
Текст = НСтр("ru = 'Текст', en = 'Text'");
```

Первый параметр — не строковый литерал (включая вложенный вызов `НСтр` — двойную локализацию) — помечает проверка **NStr string literal format**, здесь он не проверяется.
