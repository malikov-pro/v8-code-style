# Параметр метода модуля формы имеет имя «Параметры»

Проверяет, что ни один метод модуля формы не объявляет параметр с именем
**«Параметры»** (или англ. **«Parameters»**, без учёта регистра).

В модуле формы доступ к параметрам формы выполняется через свойство
`Параметры` (`Parameters`). Параметр метода с таким именем перекрывает это
свойство внутри метода и может привести к неявным ошибкам, которые трудно
обнаружить. Переименуйте параметр.

Каждый такой параметр помечается одним замечанием.

## Неправильно

```bsl
&НаСервере
Процедура ЗаполнитьДанные(Параметры)
    // Имя параметра конфликтует со свойством формы «Параметры»
    РеквизитФормы = Параметры.ИсходныйРеквизит;
КонецПроцедуры
```

## Правильно

```bsl
&НаСервере
Процедура ЗаполнитьДанные(ПараметрыЗаполнения)
    РеквизитФормы = ПараметрыЗаполнения.ИсходныйРеквизит;
КонецПроцедуры
```
