# Переменная модуля без описания

Включена по умолчанию, CODE_STYLE / MINOR. Переменная модуля без описания
оставляет читателю догадываться о её назначении и ожидаемом типе значения.

Описанием считается комментарий непосредственно над объявлением либо
комментарий в строке объявления. Аннотации (`&...`) могут стоять между
комментарием и объявлением: важно, чтобы комментарий оставался привязанным,
то есть без пустой строки. Пустая строка разрывает связь.

Маркер покрывает имя переменной. v1 работает построчно: многострочные
аргументы аннотаций между комментарием и объявлением не разбираются;
проверяется наличие описания, а не точность его смысла.
