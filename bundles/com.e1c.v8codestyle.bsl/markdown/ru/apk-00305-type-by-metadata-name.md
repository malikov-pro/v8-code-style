# Тип значения переменной следует определять сравнением с типом

Проверяет, что тип значения переменной определяется сравнением типа значения с типом, а не по имени метаданных. Определение типа по имени (полному имени) метаданных ненадёжно и может приводить к ошибкам.

## Неправильно

```bsl
Если Ссылка.Метаданные().Имя = "ПоступлениеТоваровУслуг" Тогда
    Флаг = Истина;
КонецЕсли;
```

## Правильно

```bsl
Если ТипЗнч(Ссылка) = Тип("ДокументСсылка.ПоступлениеТоваровУслуг") Тогда
    Флаг = Истина;
КонецЕсли;
```
