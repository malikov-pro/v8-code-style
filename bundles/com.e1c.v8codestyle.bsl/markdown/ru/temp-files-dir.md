# Аудит использования каталога временных файлов

Проверка **SECURITY / MAJOR**, выключена по умолчанию, без параметров. Ищет
глобальные вызовы `КаталогВременныхФайлов()` / `TempFilesDir()` без учёта
регистра. Якорь — имя вызова. Методы объектов, строки, комментарии и похожие
имена исключены — как в pinned BSL LS.

Проверьте владение временными файлами, права доступа, конкурирующие обращения
и очистку. При наличии используйте подходящий управляемый API проекта, например
средства БСП. Наличие БСП не проверяется; каждый вызов не объявляется уязвимостью.
Это не анализ потоков данных и не проверка удаления файла. Quick fix отсутствует.

Отличия от LS: SECURITY вместо CODE_SMELL и opt-in вместо включения по умолчанию
— согласованная политика аудита форка. Существующие проверки удаления файлов и
синхронных вызовов независимы; автоматически не выключаются.

Ссылки: [BSL LS](https://v8std.ru/diagnostics/bslls/TempFilesDir/),
[стандарт 542](https://v8std.ru/std/542/).
