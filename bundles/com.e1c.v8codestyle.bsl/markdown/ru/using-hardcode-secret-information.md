# Хранение конфиденциальной информации в коде

Проверяет код на хранение конфиденциальной информации (паролей) в открытом виде:

```bsl
Пароль = "12345";                      // переменная
Объект["Пароль"] = "12345";            // ключ соответствия
Объект.Пароль = "12345";               // свойство
Объект.Вставить("Пароль", "12345");    // метод Вставить
Структура = Новый Структура("Пароль", "12345");
Соединение = Новый FTPСоединение(Хост, Порт, Пользователь, "12345"); // пароль соединения
```

Ключевые слова настраиваются (параметр `searchWords`, по умолчанию `Пароль|Password`). Замаскированные значения (`"***"`) не фиксируются.

Проверка не имеет quick fix: хранение пароля — решение пользователя (БезопасноеХранение/настройки, запрос при вводе).

## Неправильно

```bsl
Пароль = "12345";
```

## Правильно

```bsl
Пароль = ЗапроситьПарольУПользователя();
```
