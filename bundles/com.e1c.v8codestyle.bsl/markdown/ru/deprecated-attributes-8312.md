# Устаревшие свойства диаграмм до 8.3.12

Лексический остаток pinned LS DeprecatedAttributes8312: старые свойства обращений с корнями Диаграмма, ДиаграммаГанта, СводнаяДиаграмма, ОбластьПостроенияДиаграммы и английскими эквивалентами. По умолчанию включена, TRIVIAL/CODE_STYLE, без параметров. Применяется при совместимости конфигурации 8.3.12 и выше.

Сохранён поиск по написанию, а не по выведенному типу: переменная Chart типа Structure может получить замечание, а псевдоним диаграммы с другим именем — нет. Удалённые имена системных перечислений оставлены штатной проверке EDT на текущем runtime. Сочетание runtime/совместимости до 8.3.12 и полная эквивалентность движку LS не сертифицированы. Автоисправление и связанные позиции не добавлены.
