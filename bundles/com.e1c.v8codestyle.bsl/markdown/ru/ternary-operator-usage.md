# Использование тернарного оператора

Вместо тернарного оператора `?(Условие, А, Б)` рекомендуется использовать конструкцию «Если … Тогда … Иначе»: она легче читается и отлаживается.

Проверка **по умолчанию отключена** (как в BSL Language Server); включается в настройках проверок.

## Неправильно

```bsl
Скидка = ?(ПостоянныйКлиент, 10, 0);
```

## Правильно

```bsl
Если ПостоянныйКлиент Тогда
	Скидка = 10;
Иначе
	Скидка = 0;
КонецЕсли;
```
