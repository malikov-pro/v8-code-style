# Отсутствует удаление из временного хранилища

Проверяет, что данные, полученные из временного хранилища (ПолучитьИзВременногоХранилища), впоследствии удаляются (УдалитьИзВременногоХранилища): без удаления данные остаются в серверной памяти до завершения сеанса. Для каждого получения требуется удаление с теми же аргументами, оператор которого начинается на строке после завершения получения. Удаление другого адреса, до получения или на той же строке не снимает замечание.

Токены аргументов сравниваются без пробелов и комментариев, имена — без учёта регистра, строковые литералы — с учётом регистра. Поиск включает вложенные операторы всего метода, как в зафиксированной реализации LS: это не анализ путей выполнения, условное удаление может снять замечание. Тело модуля не проверяется. Прежнее включение по умолчанию сохранено; в LS диагностика по умолчанию выключена. Эти отличия области и настройки остаются явными. Автоматического исправления нет.
