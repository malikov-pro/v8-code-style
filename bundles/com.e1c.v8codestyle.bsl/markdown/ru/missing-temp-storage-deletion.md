# Отсутствует удаление из временного хранилища

Проверяет, что данные, полученные из временного хранилища (ПолучитьИзВременногоХранилища), впоследствии удаляются (УдалитьИзВременногоХранилища): без удаления данные остаются в серверной памяти до завершения сеанса. Упрощение: фиксируются все вызовы ПолучитьИзВременногоХранилища метода, если в нём нет ни одного удаления. Проверка не имеет quick fix.
