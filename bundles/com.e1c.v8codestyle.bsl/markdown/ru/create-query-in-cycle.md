# Создание или выполнение запроса в цикле

Запрос (или построитель запроса/отчёта) не следует создавать и выполнять в цикле: каждая итерация цикла отправляет новый запрос к СУБД и замедляет код. Получите все данные одним запросом с условием `В (&Список)` и обработайте результат.

## Неправильно

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|	ПоступлениеТоваровУслуг.СуммаДокумента
|ИЗ
|	Документ.ПоступлениеТоваровУслуг КАК ПоступлениеТоваровУслуг
|ГДЕ
|	ПоступлениеТоваровУслуг.Ссылка = &Ссылка";

Для Индекс = 0 По СписокДокументов.ВГраница() Цикл
	Запрос.УстановитьПараметр("Ссылка", СписокДокументов[Индекс]);
	РезультатЗапроса = Запрос.Выполнить();   // запрос выполняется на каждой итерации
КонецЦикла;
```

## Правильно

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|	СУММА(ПоступлениеТоваровУслуг.СуммаДокумента) КАК СуммаДокумента
|ИЗ
|	Документ.ПоступлениеТоваровУслуг КАК ПоступлениеТоваровУслуг
|ГДЕ
|	ПоступлениеТоваровУслуг.Ссылка В(&СписокДокументов)";

Запрос.УстановитьПараметр("СписокДокументов", СписокДокументов);
РезультатЗапроса = Запрос.Выполнить();
```

## Источники

Перенос диагностики BSL Language Server `create-query-in-cycle`.

Проверка замещает `query-in-loop`, выключенную по умолчанию с 09.10.2026: в отличие от неё дополнительно охватывает построители запроса и отчёта, вложенные циклы и предикат цикла «Пока». Сквозной сценарий «цикл вызывает метод, который выполняет запрос» остался в `query-in-loop` — при необходимости включите её вручную в настройках проверок.

Quick fix не предусмотрен: модификация запроса (условие `В (&Список)`) требует решения пользователя.
