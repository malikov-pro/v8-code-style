# Оформление вырезаемых служебных комментариев

Проверяет оформление вырезаемых служебных комментариев — «// Локализация»,
«// Конец Локализация», «// _Демо начало примера», «// _Демо конец примера».
Ими обрамляют фрагменты кода, вырезаемые при сборке международной поставки
конфигурации.

Правила:

- комментарий, похожий на служебный, но записанный не канонически (другой
  регистр, разделители, пробелы) — замечание о неверном формате;
- в модуле без постфикса «Локализация» комментарии «Локализация»/
  «Конец Локализация» запрещены: национальную специфику выносят только
  в отдельные общие модули с постфиксом «Локализация»;
- в общем модуле с постфиксом «Локализация» должна быть связка
  «// Локализация» + «// Конец Локализация»;
- открывающий и закрывающий комментарии должны быть сбалансированы.

## Неправильно

```bsl
// В обычном модуле (без постфикса «Локализация»)
Процедура АдресВОблачномСервисе(Сервис, АдресОбъекта) Экспорт

    Если Сервис = "Box" Тогда
        АдресОбъекта = "https://app.box.com/files/0/";
    // Локализация
    ИначеЕсли Сервис = "Yandex" Тогда
        АдресОбъекта = "https://disk.yandex.ru/client/disk/";
    // Конец Локализация
    КонецЕсли;

КонецПроцедуры
```

```bsl
// В модуле РаботаСФайламиЛокализация
Процедура ПриОпределенииАдресаОблачногоСервиса(Сервис, АдресОбъекта)

    //Локализация       ← неверный формат (нет пробела)
    Если Сервис = "Yandex" Тогда
        АдресОбъекта = "https://disk.yandex.ru/client/disk/";
    КонецЕсли;

КонецПроцедуры
```

## Правильно

```bsl
// В обычном модуле национальная специфика — вызов в модуль-постфикс
Процедура АдресВОблачномСервисе(Сервис, АдресОбъекта) Экспорт

    Если Сервис = "Box" Тогда
        АдресОбъекта = "https://app.box.com/files/0/";
    Иначе
        РаботаСФайламиЛокализация.ПриОпределенииАдресаОблачногоСервиса(Сервис, АдресОбъекта);
    КонецЕсли;

КонецПроцедуры
```

```bsl
// В модуле РаботаСФайламиЛокализация
Процедура ПриОпределенииАдресаОблачногоСервиса(Сервис, АдресОбъекта)

    // Локализация
    Если Сервис = "Yandex" Тогда
        АдресОбъекта = "https://disk.yandex.ru/client/disk/";
    КонецЕсли;
    // Конец Локализация

КонецПроцедуры
```
