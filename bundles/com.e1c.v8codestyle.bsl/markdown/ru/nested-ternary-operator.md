# Вложенный тернарный оператор

Вложенные тернарные операторы и тернарные операторы в условиях «Если»/«ИначеЕсли» читаются с трудом, в них легко ошибиться. Используйте конструкции «Если … Тогда … Иначе» и промежуточные переменные.

Фиксируется:

- тернарный оператор внутри другого тернарного оператора (все, кроме самого внешнего);
- любой тернарный оператор в условии «Если»/«ИначеЕсли».

## Неправильно

```bsl
Результат = ?(Признак, ?(Значение > 0, 1, 2), 3);
Если ?(Признак, Истина, Ложь) Тогда
	ВыполнитьРаботу();
КонецЕсли;
```

## Правильно

```bsl
Если Признак Тогда
	Если Значение > 0 Тогда
		Результат = 1;
	Иначе
		Результат = 2;
	КонецЕсли;
Иначе
	Результат = 3;
КонецЕсли;
```
