# Повторяющееся условие в операторе «Если»

Проверяет, что условия оператора **Если … Тогда … ИначеЕсли** не повторяются: повторное условие никогда не будет проверено, его ветка недостижима.

Сравнивает значимые токены: комментарии и пробелы вне строк пропускаются, имена — без регистра, содержимое строк — точно. Ставит одно замечание на первое условие каждой группы повторов, как в LS, включая Если в теле модуля. Связанные диапазоны повторов LS не переносятся. Сравнение сохраняет скобки и написание токенов языка; это не полный перенос эквивалентности деревьев грамматики LS.

## Неправильно

```bsl
Если КодОшибки = 1 Тогда
	ВыполнитьПереподключение();
ИначеЕсли КодОшибки = 1 Тогда
	ПрерватьРаботу();
КонецЕсли;
```

## Правильно

```bsl
Если КодОшибки = 1 Тогда
	ВыполнитьПереподключение();
ИначеЕсли КодОшибки = 2 Тогда
	ПрерватьРаботу();
КонецЕсли;
```
