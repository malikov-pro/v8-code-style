# Служебные теги в комментариях

Проверяет только токены комментариев: служебные теги после `//` и пробелов по regex `serviceTags` и флагам LS. По умолчанию учитываются TODO, FIXME, отметки отладки, конструктора и заготовки обработчиков. Пустой regex отмечает все начала комментариев, как в LS, а не выключает поиск. Некорректный regex пропускается с WARNING вместо прерывания проверки. Выделяется комментарий без завершающего перевода строки. TRIVIAL/CODE_STYLE, включена по умолчанию; без автоматического исправления. В отличие от BadWords, код и содержимое строк не просматриваются.
