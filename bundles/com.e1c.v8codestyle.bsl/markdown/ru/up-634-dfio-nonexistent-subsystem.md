# Несуществующая подсистема в комментарии области «ДляВызоваИзДругихПодсистем»

Проверяет комментарии-отметки потребителей внутри области
**«ДляВызоваИзДругихПодсистем»** (англ. **«InterfaceImplementation»**):
каждая отметка вида `// Подсистема1.Подсистема2` должна называть
подсистемы, существующие в конфигурации.

Путь из нескольких сегментов разрешается иерархически от верхнеуровневой
подсистемы к вложенной, регистр не учитывается, допускается список
потребителей через запятую. Путь, не разрешающийся в существующую
подсистему, помечается замечанием на комментарий.

Упрощения: одиночное имя из одного сегмента, не совпавшее ни с одной
подсистемой, не помечается (такая строка не отличима от обычного
текстового комментария); закрывающие маркеры «// Конец …» отметками
не считаются; если в конфигурации нет ни одной подсистемы, проверка
ничего не сообщает. Заимствованные (adopted) модули проектов-расширений
не проверяются.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс

#Область ДляВызоваИзДругихПодсистем

// СтандартныеПодсистемы.ГрупповоеИзменениеОбектов // опечатка в имени подсистемы
Процедура ПечатьДокумента() Экспорт
    ...
КонецПроцедуры

#КонецОбласти

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

#Область ДляВызоваИзДругихПодсистем

// СтандартныеПодсистемы.ГрупповоеИзменениеОбъектов
Процедура ПечатьДокумента() Экспорт
    ...
КонецПроцедуры

#КонецОбласти

#КонецОбласти
```
