# Код в модуле устаревшего объекта метаданных

Проверяет, что все модули устаревшего объекта метаданных пусты. Объект считается
устаревшим, если его имя (или имя родителя верхнего уровня, например для модуля
формы) начинается с префикса **«Удалить»** (англ. **«Delete»/«Obsolete») — без
учёта регистра. Общий модуль проверяется по собственному имени.

Каждый непустой модуль устаревшего объекта помечается одним замечанием.

Модуль считается пустым, если не содержит ни одного исполнимого оператора:
комментарии и пустые строки допустимы. (Исходный алгоритм АПК считает модуль
непустым при наличии любого текста, включая комментарии — здесь принято более
мягкое правило, чтобы не помечать модули-заглушки из одних комментариев.)

## Неправильно

```bsl
// Объект метаданных «УдалитьСкладскойУчёт» помечен устаревшим,
// но в его модуле остался код
Процедура ПриЗаписи(Отказ)
    Сообщить("Логика списания больше не нужна");
КонецПроцедуры
```

## Правильно

Модуль устаревшего объекта должен быть пустым (допустимы комментарии),
а сам объект — удалён при выпуске новой версии.

```bsl
// Устаревший объект: код удалён, объект будет удалён в следующей версии
```
