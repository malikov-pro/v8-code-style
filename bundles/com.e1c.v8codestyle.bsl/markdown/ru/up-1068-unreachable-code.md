# Недостижимый код

Операторы, следующие в том же блоке за «Возврат» или «ВызватьИсключение», никогда не будут выполнены: управление всегда покидает блок на этих операторах. Такой код обычно остаётся после редактирования «чужого кода» и говорит об ошибке в алгоритме — исправьте алгоритм или удалите недостижимые операторы.

Блок — это тело метода, ветвь Если/ИначеЕсли/Иначе, тело цикла или секция Попытки/Исключения. Одно замечание на блок — на первый недостижимый оператор. Если все ветви «Если» (Если + все ИначеЕсли + Иначе) завершаются «Возвратом»/«ВызватьИсключением» (в том числе вложенным полностью терминальным «Если»), операторы после «КонецЕсли» в том же блоке тоже недостижимы.

## Неправильно

```bsl
Функция Пример(Параметр1, Параметр2)
    Если Ошибка Тогда
        ВызватьИсключение "Возникла ошибка";
        Параметр1 = Параметр2;   // никогда не выполнится
    КонецЕсли;
    Возврат Параметр1;
КонецФункции
```

## Правильно

```bsl
Функция Пример(Параметр1, Параметр2)
    Если Ошибка Тогда
        ВызватьИсключение "Возникла ошибка";
    КонецЕсли;
    Возврат Параметр1;
КонецФункции
```

## Источники

Упрощённая (лайт) реализация проверки недостижимых операторов по апстрим-issue [1C-Company/v8-code-style#1068](https://github.com/1C-Company/v8-code-style/issues/1068); сосед диагностики `UnreachableCode` BSL Language Server.

Лайт-версия не строит граф потока управления: операторы после «Прервать», «Продолжить» и «Перейти» не выявляются; мёртвые условия и код уровня модуля вне методов не проверяются. Quick fix не предусмотрен: исправление алгоритма требует решения пользователя.
