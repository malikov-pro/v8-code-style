# Неверная сигнатура обработчика события

Сравнивает число объявленных параметров назначенного обработчика с допустимыми сигнатурами события. Имя метода само по себе не доказывает назначение события формы. Отсутствие метода остаётся штатной проверкой EDT, без дублирующего замечания. По умолчанию включена, MAJOR/ERROR, без параметров.

Проверяются события корня формы, возвращённые EDT BslEventsService.getAllModuleEvents, обычные назначения событий элементов (включая extInfo) и действия команд формы. Для события элемента к диапазону разрешённого платформенного ParamSet добавляется первый неявный параметр «Элемент»; действие команды требует ровно один параметр «Команда». Платформенный контракт зависит от версии совместимости конфигурации. Полное число объявленных параметров метода должно подходить каждому известному назначенному событию; значения параметров обработчика по умолчанию это число не уменьшают. Достаточно любого допустимого диапазона ParamSet события (включая неограниченный максимум). Неназначенные методы с похожими именами пропускаются. Имена параметров, директивы компиляции и вид процедура/функция не проверяются.

Изменение имени/события в BM, состава элементов/обработчиков, замена действия команды и синхронизация Form.form пересчитывают модуль без правки BSL. Каждое назначение элемента рассматривается отдельно: назначения одного платформенного события разным методам не перезаписывают друг друга. На метод выдаётся не более одного замечания, даже если не подходят несколько назначений. Требование соответствовать всем известным назначениям строже выбора первого контракта по имени в pinned LS; это описанная политика частичной реализации, а не точная эквивалентность.

Перехваты событий расширениями и другие виды модулей в этот этап не входят; неизвестные или неразрешённые контракты пропускаются. Вариадические и межпроектные сценарии не сертифицированы. Автоисправление и связанные позиции не добавлены: в отличие от LS, частичная реализация не переписывает список параметров. Полная эквивалентность движку LS и производительность больших форм не сертифицированы.
