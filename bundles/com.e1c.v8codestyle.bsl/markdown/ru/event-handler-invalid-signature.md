# Неверная сигнатура обработчика события

Сравнивает число объявленных параметров назначенного обработчика с допустимыми сигнатурами события. Имя метода само по себе не доказывает назначение события формы. Отсутствие метода остаётся штатной проверкой EDT, без дублирующего замечания. По умолчанию включена, MAJOR/ERROR, без параметров.

Первоначальный scope — число параметров событий корня формы, возвращённых EDT BslEventsService.getAllModuleEvents. Полное число объявленных параметров метода должно подходить каждому известному назначенному событию; значения параметров обработчика по умолчанию это число не уменьшают. Достаточно любого допустимого диапазона ParamSet события (включая неограниченный максимум). Неназначенный метод с именем OnOpen не считается обработчиком. Имена параметров, директивы компиляции и вид процедура/функция не проверяются.

Изменение имени/события внутри BM и синхронизация Form.form пересчитывают модуль без правки BSL; при файловой синхронизации EDT обновляет производный список formEvents. Обработчики элементов и команд, расширения, другие модули, повторные назначения одного события и вариадические контракты требуют отдельной сертификации. Автоисправление и связанные позиции не добавлены: в отличие от LS, частичная реализация не переписывает список параметров. Полная эквивалентность LS не сертифицирована.
