# Пустой оператор

Проверяет, что в модуле нет пустых операторов «;». Лишняя точка с запятой — мусор, затрудняющий чтение кода.

## Неправильно

```bsl
Процедура Рассчитать(Параметр)

	Параметр = Параметр + 1;
	;
	Параметр = Параметр * 2;

КонецПроцедуры
```

## Правильно

```bsl
Процедура Рассчитать(Параметр)

	Параметр = Параметр + 1;
	Параметр = Параметр * 2;

КонецПроцедуры
```
