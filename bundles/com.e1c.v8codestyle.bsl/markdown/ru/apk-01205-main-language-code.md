# Код основного языка получается через Метаданные.ОсновнойЯзык

При использовании в конфигурации Библиотеки стандартных подсистем (БСП) код основного языка следует получать функцией **КодОсновногоЯзыка** общего модуля **ОбщегоНазначения**, а не обращением `Метаданные.ОсновнойЯзык` (например, `НСтр("ru = '...'", Метаданные.ОсновнойЯзыК.КодЯзыка)`).

Единственное допустимое место — функция `КодОсновногоЯзыка` самого модуля `ОбщегоНазначения` БСП.

## Неправильно

```bsl
Комментарий = НСтр("ru = 'Комментарий к проводке'", Метаданные.ОсновнойЯзык.КодЯзыка);
```

## Правильно

```bsl
Комментарий = НСтр("ru = 'Комментарий к проводке'", ОбщегоНазначения.КодОсновногоЯзыка());
```
