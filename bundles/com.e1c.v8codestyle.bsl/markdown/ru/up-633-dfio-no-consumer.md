# В области «ДляВызоваИзДругихПодсистем» не указана подсистема-потребитель

Проверяет, что каждый экспортный метод (процедура или функция) в области
**«ДляВызоваИзДругихПодсистем»** (англ. **«InterfaceImplementation»**), в
том числе во вложенных областях, имеет над объявлением
комментарий-отметку потребителя — строку вида
`// Подсистема1.Подсистема2` с именами подсистем, для вызова из которых
предназначен метод (допускается список через запятую и одна завершающая
точка).

Метод без комментария или с обычным текстовым комментарием помечается
замечанием на имя метода. Неэкспортные методы и методы вне этой области
не проверяются. Заимствованные (adopted) модули проектов-расширений
не проверяются.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс

#Область ДляВызоваИзДругихПодсистем

// нет отметки подсистемы-потребителя
Процедура ВыгрузитьДанные() Экспорт
    ...
КонецПроцедуры

#КонецОбласти

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

#Область ДляВызоваИзДругихПодсистем

// СтандартныеПодсистемы.ГрупповоеИзменениеОбъектов
// Процедура выгружает данные за период.
Процедура ВыгрузитьДанные() Экспорт
    ...
КонецПроцедуры

#КонецОбласти

#КонецОбласти
```
