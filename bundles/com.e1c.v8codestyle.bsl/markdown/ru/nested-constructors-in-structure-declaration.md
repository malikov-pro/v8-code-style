# Вложенные конструкторы при объявлении структуры

Отмечает конструктор Структуры/ФиксированнойСтруктуры с несколькими аргументами, если прямой аргумент начинается с конструктора хотя бы с одним непустым аргументом. Пустые конструкторы, вызовы-обёртки и конструкторы копирования структуры с одним аргументом исключены. Проверяются методы и тело модуля. Выделяется внешний конструктор, MINOR/WARNING, включена по умолчанию; без параметров и автоматического исправления. Список связанных диапазонов вложенных конструкторов LS не переносится.
