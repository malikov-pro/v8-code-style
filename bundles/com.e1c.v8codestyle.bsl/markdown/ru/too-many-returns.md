# Слишком много возвратов

Считает все операторы Возврат в функции или процедуре, включая вложенные и недостижимые. При превышении `maxReturnsCount` (по умолчанию 3) ставится одно замечание на имя метода. Пути выполнения не анализируются. MINOR/WARNING, по умолчанию выключена как в LS. Без автоматического исправления; связанные диапазоны возвратов LS не переносятся.
