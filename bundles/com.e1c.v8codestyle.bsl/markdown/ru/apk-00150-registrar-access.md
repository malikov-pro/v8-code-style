# Самодостаточность регистров: обращение к реквизиту «Регистратор»

Регистр должен быть логически независим от регистраторов. Любая логика, опирающаяся на данные регистра, а также любые отчёты по регистру не должны обращаться к полям регистратора — им должно быть достаточно данных самого регистра.

Обращение к полям регистратора через точку приводит к неявным соединениям с дополнительными таблицами. Кроме того, в распределённой информационной базе регистратора может не быть: движения регистров мигрируют между узлами, а регистраторы — нет.

Проверка выполняется в модуле набора записей регистра. Поиск охватывает текст модуля, включая комментарии и строковые литералы с текстами запросов. Каждое вхождение `.Регистратор.` / `.Recorder.` помечается замечанием.

Допустимые обращения (не помечаются):

- `Отбор.Регистратор` / `Filter.Recorder`
- `СтандартныеРеквизиты.Регистратор` / `StandardAttributes.Recorder`
- `Регистратор.ТипЗначения` / `Recorder.ValueType`
- `Регистратор.Метаданные()` / `Recorder.Metadata()`
- `Регистратор.ПолучитьОбъект()` / `Recorder.GetObject()`
- `Регистратор.МоментВремени()` / `Recorder.MomentOfTime()`

## Неправильно

```bsl
Процедура ПередЗаписью(Отказ, Замена)

	Для Каждого Запись Из ЭтотОбъект Цикл
		Если Запись.Регистратор.Дата > ТекущаяДатаСеанса() Тогда
			Отказ = Истина;
		КонецЕсли;
	КонецЦикла;

КонецПроцедуры
```

## Правильно

```bsl
Процедура ПередЗаписью(Отказ, Замена)

	ЭтотОбъект.Отбор.Регистратор.Установить(Значение); // отбор по регистратору допустим

КонецПроцедуры
```
