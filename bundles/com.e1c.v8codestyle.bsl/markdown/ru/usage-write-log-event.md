# Полнота записи в журнал регистрации

WARNING/TRIVIAL, включена по умолчанию, без параметров и автоисправления.
Проверяет глобальные ЗаписьЖурналаРегистрации / WriteLogEvent в методах и теле
модуля; одноимённые member-вызовы исключены. Выделяется весь вызов.

На вызов выдаётся одно сообщение по приоритету: менее пяти аргументов; пустой
второй аргумент; пустой пятый; известный уровень не Ошибка внутри Исключения;
отсутствие подробностей ошибки в комментарии внутри Исключения. Опциональные
аргументы платформы остаются допустимыми: это рекомендация по полезности записи,
не синтаксическая ошибка и не запрет безопасности.

Сохраняются лексические ограничения pinned LS. Неизвестная переменная/функция
уровня не считается заведомо неверной. ВызватьИсключение в том же блоке может
снять требование подробностей. Распознаются ПодробноеПредставлениеОшибки с
ИнформацияОбОшибке и соответствующий helper ОбработкаОшибок, включая EN-имена.
Присваивание переменной-комментария ищется только в первом операторе того же
блока; неизвестное присваивание принимается, а не разрешается межмодульно.
Это не полноценный анализ потока данных.
