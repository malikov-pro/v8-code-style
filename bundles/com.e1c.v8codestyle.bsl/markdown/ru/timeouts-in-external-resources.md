# Таймауты при работе с внешними ресурсами

Проверяет, что при создании `FTPСоединение`, `HTTPСоединение`, `WSОпределения`, `WSПрокси` и `ИнтернетПочтовыйПрофиль` указан таймаут: либо заполнен параметр конструктора таймаута (числом или переменной), либо ниже по коду переменной присвоено свойство «Таймаут» числом или переменной. Без таймаута сеанс может зависнуть неопределённо долго.

Индексы параметров как в BSL Language Server: WSОпределения — 4, FTPСоединение — 6, остальные — 5. Параметр `analyzeInternetMailProfileZeroTimeout` включает анализ `ИнтернетПочтовыйПрофиль` (по умолчанию включён). Проверка не имеет quick fix.

## Неправильно

```bsl
Соединение = Новый HTTPСоединение("server");
```

## Правильно

```bsl
Соединение = Новый HTTPСоединение("server", , , , , 60);
```
