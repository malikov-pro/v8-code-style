# Цикломатическая сложность метода выше допустимой

Проверяет цикломатическую сложность метода: 1 плюс число ветвей «Если»/«ИначеЕсли», циклов, операций «И»/«ИЛИ» и тернарников (параметр, по умолчанию 20, как в BSL LS). Сложный метод разбивайте на несколько. Проверка не имеет quick fix.
