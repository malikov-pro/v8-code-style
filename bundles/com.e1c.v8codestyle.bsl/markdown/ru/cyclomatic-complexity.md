# Цикломатическая сложность метода выше допустимой

Проверяет цикломатическую сложность методов и тела модуля. По умолчанию `complexityThreshold=20`, `checkModuleBody=true`. Метод начинается с единицы, тело модуля — с нуля. Если/ИначеЕсли/Иначе, циклы, Исключение, тернарники, Перейти, прямые рекурсивные вызовы и каждая операция И/ИЛИ дают единицу. Попытка, Возврат и обычные вызовы не увеличивают метрику. Достижимость не анализируется.

Замечание метода выделяет его имя, тела модуля — первый токен оператора. Численные регрессии включают адаптированный корпус вычислителя зафиксированной версии LS. Вторичные диапазоны не переносятся; полная дифференциальная эквивалентность, особенно для вложенных конструкций грамматики и препроцессора, не подтверждена. Сложный код разбивайте на меньшие методы. Автоматического исправления нет.
