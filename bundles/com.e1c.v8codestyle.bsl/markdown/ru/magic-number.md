# Магическое число

Проверяет код на магические числа. Вместо необъяснённых чисел используйте именованные константы. Не фиксируются разрешённые числа (параметр, по умолчанию «-1, 0, 1»), индексный доступ, значения по умолчанию параметров и плоские компоненты вызова «Дата(...)». Проверка не имеет quick fix.
