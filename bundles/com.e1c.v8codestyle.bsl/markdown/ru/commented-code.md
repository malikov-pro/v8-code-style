# Закомментированный фрагмент кода

Проверяет, что программные модули не содержат закомментированных фрагментов кода. Место неиспользуемого кода — в системе контроля версий, а не в комментариях.

Смежные строки комментариев группируются; группа фиксируется, если распознаётся как код (эвристика перенесена из BSL Language Server; параметр `threshold`, по умолчанию 0.9). Документирующие шапки методов не фиксируются; параметр `exclusionPrefixes` исключает комментарии с заданными префиксами.

Quick fix удаляет закомментированную группу.

## Неправильно

```bsl
//А = 1;
//Б = 2;
//Сообщить(А + Б);
```

## Правильно

Удалите закомментированный код (он остаётся в истории системы контроля версий).
