# НСтр должна содержать все заявленные языки

Включена по умолчанию, ERROR / MINOR. Параметр `declaredLanguages` по умолчанию
равен `ru`. Явный список через запятую не зависит от языков конфигурации:
пробельные символы удаляются, регистр и повторы сохраняются как в pinned LS.
Ключи языков ищутся лексически, без исполнения кода и полной проверки формата
НСтр. Неверный формат независимо может отметить существующая проверка НСтр.

Маркер охватывает весь глобальный вызов НСтр. Переменная вместо строкового
аргумента и методы объектов исключены. Вызовы с ошибками синтаксического
восстановления пропускаются. Также исключаются НСтр внутри СтрШаблон и результат
присваивания, переданный целым аргументом в более поздний СтрШаблон того же блока.
Учитывается более поздняя строка; переприсваивание, достижимость и идентичность
переменной не анализируются.

Существующая `bsl-nstr-string-literal-format` и `checkEmptyInterface` не меняются.
При ручном включении проверки языков проекта возможны дополнительные замечания.
Автоотключения, генерации переводов и быстрого исправления нет.
