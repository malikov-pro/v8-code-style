# Устаревшее свойство платформы

Остаток pinned LS DeprecatedMethodCall: разрешённые свойства платформы с метаданными deprecatedSince. По умолчанию включена, MINOR/CODE_STYLE, без параметров. Устаревание сравнивается с режимом совместимости конфигурации; версия runtime проекта EDT определяет платформенную модель, из которой читаются метаданные. Отсутствие этих данных не доказывает актуальность члена.

Штатные проверки устаревших глобальных методов и создаваемых типов не дублируются. Существующие проверки устаревших пользовательских методов остаются отдельно. Удалённые имена, свойства конфигурации с префиксом «Удалить» и полный охват LS в этот этап не входят. Автозамена и связанные позиции не добавлены; полная эквивалентность движку LS не сертифицирована.
