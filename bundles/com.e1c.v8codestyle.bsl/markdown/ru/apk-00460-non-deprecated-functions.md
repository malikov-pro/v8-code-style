# Неустаревшая функция в переопределяемом общем модуле

Проверяет, что переопределяемый общий модуль (в имени содержится
**«Переопределяемый»**/«Override», без учёта регистра) не содержит функций,
кроме устаревших. Каждая неустаревшая функция помечается отдельным
замечанием.

Функция в переопределяемом модуле никогда не будет вызвана механизмом
переопределения: переопределяются только процедуры. Устаревшие функции
допустимы для обратной совместимости.

Функция считается устаревшей, если:

- помечена комментарием **«Устарела.»** (англ. **«Deprecated.»**);
- размещена в области **«УстаревшиеПроцедурыИФункции»** (англ. «Deprecated»).

Заимствованные (adopted) общие модули проектов-расширений не проверяются.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс

// Функция в переопределяемом модуле не будет вызвана
Функция ДанныеДляЗаполнения(Параметры) Экспорт
    Возврат Неопределено;
КонецФункции

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

// Устарела. Используйте процедуру ЗаполнитьДанные.
Функция ДанныеДляЗаполнения(Параметры) Экспорт
    Возврат Неопределено;
КонецФункции

Процедура ЗаполнитьДанные(Параметры) Экспорт
    ...
КонецПроцедуры

#КонецОбласти
```
