# Цепочка Если/ИначеЕсли без Иначе

Цепочка Если хотя бы с одним ИначеЕсли должна иметь Иначе. Простому Если ветка Иначе не требуется. Пустое Иначе допустимо; ветка вложенного Если не заменяет Иначе внешней цепочки. Проверяются методы и тело модуля, выделяется КонецЕсли. По умолчанию включена, MAJOR/WARNING, без параметров и автоматического исправления.
