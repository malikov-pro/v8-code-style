# Недостижимый код после выхода из цикла или Перехода

Операторы после «Прервать», «Продолжить» и «Перейти» никогда не выполнятся. Используется тот же граф потока управления, что и в `all-function-path-must-have-return` (по методу во время валидации, без кэша между валидациями). По умолчанию включена, серьёзность MINOR, тип ERROR, без параметров.

Решение о рамках (вариант B): операторы после «Возврат» и «ВызватьИсключение» и полностью терминальные цепочки «Если» здесь намеренно НЕ помечаются — их уже маркирует платформенная проверка `bsl-legacy-check-method-for-statements-after-return` и `up-1068-unreachable-code`; третий маркер был бы дублем. Ветви препроцессора консервативно считаются все возможными, поэтому «мёртвый» код внутри невыглядящих-активными ветвей не помечается. Фрагменты с синтаксическими ошибками пропускаются.

Основа: диагностика UnreachableCodeDiagnostic BSL Language Server (графовая часть); полная эквивалентность её диапазонов и обработки препроцессорных границ в этой версии не заявляется — один маркер на группу недостижимых операторов.
