# Несуществующая процедура в параметре обработчика оповещения

Проверяет, что имя обработчика оповещения, переданное первым параметром в вызов `ОповеститьОбИзменении` (`NotifyChanged`), разрешается в существующую экспортную процедуру или функцию серверного общего модуля конфигурации.

Платформа позволяет устанавливать серверные процедуры в качестве обработчиков оповещения. Имя, не разрешающееся ни в один метод, означает потерянное оповещение: платформа молча игнорирует вызов, и ошибка обнаруживается только при тестировании.

## Неправильно

```bsl
// Обработчика нет ни в одном серверном общем модуле (опечатка).
ОповеститьОбИзменении("ПриИзминенииДанных", Данные);

// Указанного общего модуля не существует.
ОповеститьОбИзменении("ОбщегоНазначенияНесуществующий.ПриИзмененииДанных", Данные);
```

## Правильно

```bsl
// Экспортная процедура серверного общего модуля.
ОповеститьОбИзменении("ОбменДаннымиСервер.ПриИзмененииДанных", Данные);

// Форма вызова с объектом не требует обработчика.
ОповеститьОбИзменении(ЭтотОбъект);
```

Имя обработчика может быть простым (`ИмяПроцедуры`) или составным (`ИмяМодуля.ИмяПроцедуры`); сравнение без учёта регистра. Проверяется только строковый литерал в первом параметре: переменная или выражение не разрешаются. Проверка не применяется к модулям, заимствованным в расширениях, где обработчик может находиться в родительской конфигурации.
