# Функция СУММА() с числовым операндом в запросах в текстах модулей

Проверяет, что тексты запросов в модулях не содержат вызова функции `СУММА()` с константным числовым операндом для подсчёта количества записей: при количестве записей 10 млн и более произойдёт переполнение из-за разрядности числа по умолчанию, используемой платформой в СУБД. Для вычисления количества записей следует всегда использовать функцию `КОЛИЧЕСТВО`.

Как и в исходном алгоритме АПК, не фиксируются: `СУММА(0)` и вызовы с нечисловым операндом (поле или выражение, например `СУММА(ВЫБОР … КОНЕЦ)`). Каждое вхождение помечается отдельным замечанием.

## Неправильно

```bsl
Процедура КоличествоЗаписей()
	
	Запрос = Новый Запрос;
	Запрос.Текст =
	"ВЫБРАТЬ
	|	СУММА(1) КАК Количество
	|ИЗ
	|	Справочник.Номенклатура КАК Номенклатура";
	
КонецПроцедуры
```

## Правильно

```bsl
Процедура КоличествоЗаписей()
	
	Запрос = Новый Запрос;
	Запрос.Текст =
	"ВЫБРАТЬ
	|	КОЛИЧЕСТВО(*) КАК Количество
	|ИЗ
	|	Справочник.Номенклатура КАК Номенклатура";
	
КонецПроцедуры
```
