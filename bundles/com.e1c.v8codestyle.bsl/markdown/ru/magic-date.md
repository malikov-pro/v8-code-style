# Магическая дата

Проверяет код на магические даты (литералы вида '20240101'). Пустая дата, разрешённые даты (параметр), значения по умолчанию параметров, правая часть простого присваивания и выражение «Возврат» не фиксируются (как в BSL LS). Проверка не имеет quick fix.
