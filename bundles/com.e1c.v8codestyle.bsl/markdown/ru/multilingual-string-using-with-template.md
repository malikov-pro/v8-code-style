# Частично локализованная НСтр используется в СтрШаблон

Включена по умолчанию, ERROR / MAJOR. Пустой локализованный шаблон может привести
к исключению во время исполнения. Параметр `declaredLanguages` по умолчанию равен
`ru` и не читает языки конфигурации. В списке через запятую удаляются пробельные
символы; регистр, повторы и пустые элементы обрабатываются лексически как в pinned LS.

Маркер охватывает весь глобальный вызов НСтр, не вызов СтрШаблон. Ключи языков
извлекаются лексически, без исполнения кода и полного разбора формата НСтр.
Нестроковый первый аргумент и методы объектов исключены. Вызовы с локальными
ошибками синтаксического восстановления пропускаются, в отличие от recovery-корпуса LS.

Шаблонный случай — глобальный СтрШаблон среди предков до содержащего оператора
либо левая часть присваивания, переданная целым аргументом в более поздней строке
глобальному СтрШаблон того же блока кода, включая вложенные блоки. Скобки или
конкатенация в этом аргументе уже не считаются совпадением целого выражения.
Достижимость, идентичность ссылки и переприсваивание не анализируются.

Обычная `multilingual-string-has-all-declared-languages` использует тот же
классификатор с противоположной веткой. При одинаковых параметрах эти проверки
не пересекаются; параметры можно настроить независимо. Существующая
`bsl-nstr-string-literal-format` и опциональная `checkEmptyInterface` не меняются:
ручное включение аудита языков проекта может добавить замечания. Автодедупликации,
автоотключения, генерации переводов и быстрого исправления нет.
