# Бессмысленные методы в общем модуле с повторным использованием

Проверяет общие модули с повторным использованием возвращаемых значений: **экспортная процедура** бессмысленна, так как процедуры не возвращают значения, а **функция из единственного оператора `Возврат <константа>`** возвращает данные, вычисление которых быстрее, чем получение из кэша. Такие константы (строка, число, булево, дата) и предопределённые элементы (`Справочники.X.Y` и аналогичные) занимают память кэша без пользы.

## Неправильно

```bsl
// Общий модуль с повторным использованием возвращаемых значений
Процедура ИмяПакетаУправления() Экспорт
    
КонецПроцедуры

Функция ИмяПакета() Экспорт
    Возврат "ManagementPackage";
КонецФункции
```

## Правильно

```bsl
// Общий модуль с повторным использованием возвращаемых значений
Функция ИмяПриложения() Экспорт
    Возврат ЭтотОбъект.ИмяПриложения; // вычисляемое значение, а не константа
КонецФункции
```

Выносите возвращаемые константы из кэшируемых общих модулей либо делайте так, чтобы функция возвращала действительно дорогой в вычислении результат (запрос к базе данных, внешнему источнику данных, ресурсоёмкое вычисление).
