# Внешняя область, кроме «ПрограммныйИнтерфейс», в переопределяемом общем модуле

Проверяет, что переопределяемый общий модуль (в имени содержится
**«Переопределяемый»**/«Override», без учёта регистра) не содержит внешних
(верхнеуровневых) областей, кроме **«ПрограммныйИнтерфейс»** (англ. «Public»).
Каждая недопустимая область помечается отдельным замечанием.

Весь код переопределяемого модуля размещается в области
«ПрограммныйИнтерфейс»; вложенные области (внутри других областей) допустимы.

Заимствованные (adopted) общие модули проектов-расширений не проверяются.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс
...
#КонецОбласти

#Область СлужебныеПроцедурыИФункции
// Внешняя область в переопределяемом модуле не допускается
...
#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

Процедура ПриОпределенииНастроек(Настройки) Экспорт
    ...
КонецПроцедуры

#КонецОбласти
```
