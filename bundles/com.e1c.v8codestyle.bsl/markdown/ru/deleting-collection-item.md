# Удаление элемента при обходе коллекции

Проверяет, что элементы коллекции не удаляются при её обходе оператором **Для каждого … Из … Цикл**: при удалении элемента сдвигается индекс следующего, часть элементов будет пропущена.

## Неправильно

```bsl
Для Каждого Элемент Из Коллекция Цикл
	
	Коллекция.Удалить(Элемент);
	
КонецЦикла;
```

## Правильно

Соберите элементы для удаления во временную коллекцию и удалите их после цикла (либо обойдите цикл в обратном порядке по индексу).
