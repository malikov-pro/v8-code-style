# Обращение в программном коде к менеджеру регламентных заданий

В решениях, ориентированных на работу в модели сервиса (1cFresh), не должно быть участков кода с прямым управлением регламентными заданиями. Проверка фиксирует начало цепочки обращения к менеджеру регламентных заданий — «РегламентныеЗадания» («ScheduledJobs»).

Для управления заданиями используйте программный интерфейс БСП из модуля **РегламентныеЗаданияСервер** (`НайтиЗадания`, `ДобавитьЗадание`, `ИзменитьЗадание`, `УдалитьЗадание`).

Обращения вида «Метаданные.РегламентныеЗадания» и обращения к модулю «РегламентныеЗаданияСервер» не фиксируются. Общие модули с именем, начинающимся на «РегламентныеЗадания», не проверяются.

Проверка **выключена по умолчанию**: предусловие АПК «в решении есть подсистема ТехнологияСервиса/БСП» статически не воспроизводится, поэтому включайте её для решений на БСП.

## Неправильно

```bsl
// Ищем задание по наименованию.
Отбор = Новый Структура();
Отбор.Вставить("Метаданные", "ПроверкаЦен");
Задания = РегламентныеЗадания.ПолучитьРегламентныеЗадания(Отбор);
```

## Правильно

```bsl
// Ищем задание по наименованию.
Отбор = Новый Структура();
Отбор.Вставить("Метаданные", "ПроверкаЦен");
Задания = РегламентныеЗаданияСервер.НайтиЗадания(Отбор);
```
