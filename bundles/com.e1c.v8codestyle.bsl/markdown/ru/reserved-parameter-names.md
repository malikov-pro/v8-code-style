# Зарезервированные имена параметров

Сопоставляет параметры функций и процедур с `reservedWords` — регулярным выражением без учёта регистра. Пустое значение по умолчанию ничего не запрещает. Шаблон обрезается по краям и ограничивается как в LS (`^` + шаблон + `$`); для альтернатив используйте группировку. Некорректное выражение пропускается с предупреждением, не прерывая проверку. По умолчанию включена, MAJOR/WARNING; без автоматического исправления. Это настраиваемый шаблон, а не фиксированный список слов платформы.
