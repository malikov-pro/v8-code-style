# Имя параметра метода модуля объекта совпадает с именем реквизита или табличной части

Проверяет, что ни один метод модуля объекта (справочника, документа и т.п.)
не объявляет параметр, имя которого (без учёта регистра) совпадает с именем
реквизита или табличной части того же объекта метаданных.

Такое имя перекрывает член объекта (реквизит или табличную часть) внутри
метода и может привести к неявному поведению или ошибке при выполнении,
которые трудно обнаружить. Переименуйте параметр.

Сравниваются только прикладные реквизиты и имена табличных частей верхнего
уровня:

- реквизиты табличных частей **не** сравниваются;
- стандартные реквизиты (Код, Наименование, ЭтотОбъект и т.п.) **не**
  сравниваются — параметр метода не конфликтует с ними в областях видимости.

Каждый совпавший параметр помечается одним замечанием.

## Неправильно

```bsl
// Справочник «Товары»: реквизит «Штрихкод», табличная часть «Остатки»

Процедура ЗаполнитьПоШтрихкоду(Штрихкод)
    // Имя параметра совпадает с именем реквизита Штрихкод
    Сообщить(Штрихкод);
КонецПроцедуры

Процедура ПересчитатьОстатки(Остатки)
    // Имя параметра совпадает с именем табличной части Остатки
    Сообщить(Остатки);
КонецПроцедуры
```

## Правильно

```bsl
Процедура ЗаполнитьПоШтрихкоду(ЗначениеШтрихкода)
    Сообщить(ЗначениеШтрихкода);
КонецПроцедуры

Процедура ПересчитатьОстатки(ТаблицаОстатков)
    Сообщить(ТаблицаОстатков);
КонецПроцедуры
```
