# Неиспользуемый итератор Для Каждого

Проверяет циклы Для Каждого в методах и теле модуля. Локальный итератор должен использоваться в теле: чтение, присваивание и обращение к свойству учитываются. Строки, комментарии и вызов одноимённого метода не учитываются. Переменные модуля и глобальные исключены. CRITICAL/ERROR, включена по умолчанию; без параметров и автоматического исправления. Разрешение символа используется при наличии, иначе сравниваются имена. Одно определение итератора вложенного цикла не считается использованием внешнего.
