# Сложное условие в операторе «Если»

Проверяет количество условий в «Если»/«ИначеЕсли»: число логических операций «И»/«ИЛИ» плюс один, как в BSL LS. Параметр `maxIfConditionComplexity` по умолчанию равен 3: три условия с двумя операциями допустимы, четыре условия с тремя операциями дают замечание. Скобки и «Не» не увеличивают счётчик. Сложное условие разбивайте на промежуточные переменные или отдельные операторы. Автоматического исправления нет.
