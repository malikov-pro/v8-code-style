# Сложное условие в операторе «Если»

Проверяет, что в условии «Если»/«ИначеЕсли» не больше логических операций «И»/«ИЛИ», чем максимум (параметр, по умолчанию 3, как в BSL LS). Сложное условие разбивайте на промежуточные переменные или отдельные операторы. Проверка не имеет quick fix.
