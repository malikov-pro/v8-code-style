# Неверный формат версии в обработчике обновления ИБ

Версия, назначаемая обработчику в процедуре **ПриДобавленииОбработчиковОбновления** (`Обработчик.Версия = "..."`), должна быть либо `*` (выполнять при каждом обновлении ИБ), либо номером версии в формате **«Р.П.В.С»** или **«Р.П.В»**: не менее трёх сегментов, разделённых точками, каждый сегмент — только цифры.

Пустая версия не помечается (по стандарту она должна сопровождаться свойством `НачальноеЗаполнение = Истина`, что вне рамок проверки).

## Неправильно

```bsl
Процедура ПриДобавленииОбработчиковОбновления(Обработчики)

    Обработчик = Обработчики.Добавить();
    Обработчик.Версия = "2.1";     // всего два сегмента
    Обработчик.Версия = "2.1.Х";   // нецифровой сегмент

КонецПроцедуры
```

## Правильно

```bsl
Процедура ПриДобавленииОбработчиковОбновления(Обработчики)

    Обработчик = Обработчики.Добавить();
    Обработчик.Версия = "2.1.3.1";
    Обработчик.Версия = "*";

КонецПроцедуры
```
