# Французские кавычки «ёлочки» в интерфейсных текстах

Проверяет, что в интерфейсных текстах — строковых литералах функции **НСтр** — не используются французские кавычки «ёлочки». Для кавычек в интерфейсных текстах следует использовать прямые двойные кавычки.

Кавычки вне `НСтр` не проверяются: в текстах справки французские кавычки допустимы.

## Неправильно

```bsl
Сообщение = НСтр("ru = 'Документ «Реализация товаров» не проведен'");
```

## Правильно

```bsl
Сообщение = НСтр("ru = 'Документ ""Реализация товаров"" не проведен'");
```
