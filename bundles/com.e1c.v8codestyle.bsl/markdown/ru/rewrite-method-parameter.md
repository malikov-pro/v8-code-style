# Перезапись параметров метода

Проверяет, что параметр, переданный по значению (`Знач`), не перезаписывается до первого использования. Переданное значение теряется — вероятная ошибка.

Модификация вида `Параметр = Параметр + 1` перезаписью не считается (параметр читается); параметры, переданные по ссылке (без `Знач`), не проверяются — как в BSL Language Server. Маркер ставится на первое переприсваивание параметра.

Чтение в аргументе вызова, условии, выражении цикла, корне правой части присваивания и обращении к свойству считается использованием. Имя вызываемого метода не считается чтением одноимённого параметра. Самоприсваивания (`Параметр = Параметр`) не используют и не перезаписывают исходное значение: последующее `Параметр = 12` всё ещё может дать замечание.

Проверка идёт в порядке исходного текста, без анализа достижимости ветвей. Проверяются прямые присваивания, но не определения переменной цикла. В отличие от LS, нет индекса ссылок и списка связанных обращений; маркер выделяет оператор присваивания, а не только имя параметра. Эти ограничения не позволяют заявить полную эквивалентность LS.

## Неправильно

```bsl
Процедура ЗаполнитьЗаказ(Знач Заказ, Знач ИспользоватьСкидку)
	Заказ = Неопределено; // переданное значение теряется
	Если ИспользоватьСкидку Тогда
		ПрименитьСкидку(Заказ);
	КонецЕсли;
КонецПроцедуры
```

## Правильно

```bsl
Процедура ЗаполнитьЗаказ(Заказ, Знач ИспользоватьСкидку)
	Если ИспользоватьСкидку Тогда
		ПрименитьСкидку(Заказ);
	КонецЕсли;
КонецПроцедуры
```
