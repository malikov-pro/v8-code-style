# Устаревшая процедура (функция) ссылается на другую устаревшую процедуру (функцию)

Устаревшая процедура (функция) — помеченная «Устарела.»/«Deprecated.»,
размещённая в области «УстаревшиеПроцедурыИФункции» либо имеющая признак
устаревания в контексте модуля — должна ссылаться на **актуальную**
(неустаревшую) замену. Проверка разбирает комментарий-описание над объявлением
метода и разрешает каждую отсылку «см. Модуль.ИмяМетода» (в любом регистре;
распознаётся и английское `see`; между «см.» и именем допускается одно слово —
«см. также …»). Если целевой метод найден в общих модулях конфигурации и сам
устарел — регистрируется замечание: отсылка вводит разработчиков в заблуждение —
по ней они приходят к другому тупиковому методу.

Ссылка на несуществующий метод или модуль помечается отдельной проверкой
`up-768-obsolete-refs-missing`.

Упрощения: цели ищутся по общим модулям конфигурации; проверяются только общие
модули; ссылки на методы объектных модулей и глобальный контекст не
разрешаются.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс

// Устарела. Следует использовать новую (см. CommonModule.НоваяФункция).
Функция СтараяФункция() Экспорт

	Возврат Истина;

КонецФункции

// Устарела. Оставлена для обратной совместимости.
Функция НоваяФункция() Экспорт

	Возврат Истина;

КонецФункции

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

// Устарела. Следует использовать новую (см. CommonModule.АктуальнаяФункция).
Функция СтараяФункция() Экспорт

	Возврат Истина;

КонецФункции

// Актуальная функция-замена.
Функция АктуальнаяФункция() Экспорт

	Возврат Истина;

КонецФункции

#КонецОбласти
```
