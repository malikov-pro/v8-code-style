# Бесполезный тернарный оператор

Проверяет тернарный оператор `?(Условие, Ветка1, Ветка2)`, результат которого известен заранее:

- условие — булева константа: `?(Истина, А, Б)`;
- обе ветки — булевы константы: `?(X, Истина, Ложь)` — это `X`, `?(X, Ложь, Истина)` — это `НЕ X`;
- обе ветки одинаковы: `?(X, Истина, Истина)`.

Quick fix упрощает случаи с булевыми константами в ветках. Остальные случаи — на усмотрение пользователя.

## Неправильно

```bsl
Результат = ?(Признак, Истина, Ложь);
Значение = ?(Истина, 1, 2);
```

## Правильно

```bsl
Результат = Признак;
Значение = 1;
```
