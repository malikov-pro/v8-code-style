# Слишком большая вложенность операторов

Проверяет глубину вложенности Если, Пока, Для, Для Каждого и Попытки в методах и теле модуля. Параметр `maxAllowedLevel` по умолчанию равен 4; внешний составной оператор имеет глубину 1. Отмечаются только конечные составные блоки глубже лимита, не все их предки. Глубокие соседние блоки проверяются отдельно. Метка не увеличивает глубину и не скрывает свой оператор. Замечание выделяет начальное ключевое слово. Пути выполнения не анализируются; автоматического исправления нет.

Обёртки операторов препроцессора Если и Область не добавляют уровень вложенности:
обходятся их ветви и следующие за директивами операторы. Регрессии проверяют
глубокие блоки через границу препроцессора, соседние ветви, области и код после
директив, позиции ключевых слов и исчезновение/восстановление маркеров.
Анализируются обе ветви исходного текста, не только активная в одном окружении.

Список связанных диапазонов родительских блоков LS не переносится. Полный корпус
препроцессора и грамматики LS не пройден; реализация остаётся частичной.
