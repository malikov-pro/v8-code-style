# Функция возвращает один примитив

Проверяет функции с несколькими Возврат, выражения которых текстово совпадают и не содержат обращений к переменным/свойствам/вызовам. Достижимость и вычисление констант не анализируются. `skipAttachable=true` исключает Подключаемый_/Attachable_; `caseSensitiveForString=false` сравнивает текст строк без регистра. Проверяются обычные функции, не только кешируемые модули как в АПК00350. Выделяется имя функции. MAJOR/ERROR, включена по умолчанию; без автоматического исправления. Связанные диапазоны возвратов LS не переносятся. Возврат без выражения консервативно исключён вместо nullable-сокращения LS.
