# Разделитель пути и маска всех файлов указаны вручную

В ОС Windows разделитель пути — обратный слэш («\»), маска всех файлов — «*.*»; в ОС Linux разделитель — прямой слэш («/»), маска всех файлов — «*». Жёстко заданные разделители и маски ломают решение при переходе между операционными системами (статья 723 стандарта, п. 2.5.2).

Используйте функции платформы:

- `ПолучитьРазделительПути` (GetPathSeparator) — для разделителя пути;
- `ПолучитьМаскуВсеФайлы` (GetAllFilesMask) — для маски всех файлов;
- в решениях на БСП — функции общих модулей `ОбщегоНазначения` и `ОбщегоНазначенияКлиент`.

Проверяются литеральные строковые параметры методов поиска файлов, как в исходном алгоритме АПК:

- `НайтиФайлы` (FindFiles) — параметры 1 (каталог) и 2 (маска);
- `НачатьПоискФайлов` (BeginFindingFiles) — параметры 2 (каталог) и 3 (маска);
- конструктор `Новый Файл` (New File) — параметр 1 (путь).

Каждый нарушающий параметр помечается одним замечанием. Параметры-переменные и выражения не проверяются.

## Неправильно

```bsl
Найденные = НайтиФайлы("C:\Обмен\", "*.*");          // ручные разделитель и маска
Файл = Новый Файл("C:\Обмен\Данные.xml");            // ручные разделители
```

## Правильно

```bsl
Каталог = "C:\Обмен";
Найденные = НайтиФайлы(Каталог + ПолучитьРазделительПути(), ПолучитьМаскуВсеФайлы());
Файл = Новый Файл(Каталог + ПолучитьРазделительПути() + "Данные.xml");
```
