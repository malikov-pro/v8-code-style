# Аудит обращения к интернет-ресурсам

Проверка SECURITY/MAJOR конструкторов `FTPСоединение`, `HTTPСоединение`,
`WSОпределения`, `WSПрокси`, `ИнтернетПочтовыйПрофиль`, `ИнтернетПочта`, `Почта`,
`HTTPЗапрос`, `ИнтернетПрокси` и их английских имён. Выключена по умолчанию,
без параметров и быстрого исправления. Проверьте необходимость сетевого доступа,
доверие к адресату и обработку передаваемых данных. Замечание указывает место
для аудита, а не доказывает уязвимость или фактическое сетевое соединение.

Проверяются явные конструкторы и динамический `Новый("ИнтернетПочта")`
в методах и теле модуля. Имена сопоставляются целиком, без учёта регистра.
По синтаксической семантике pinned BSL Language Server имя берётся из первого
строкового литерала первого аргумента, пробелы по краям удаляются:
`Новый("InternetMail" + Суффикс)` отмечается, строка в скобках и переменное
имя типа не вычисляются. Выделяется весь конструктор. Устаревший тип `Почта`
сохранён для совместимости с LS, даже если он недоступен в выбранном контексте.

Проверки таймаутов и жёстко заданных адресов ищут другие нарушения и независимы.
Включение аудита не отключает их: разные сообщения на одном конструкторе могут
быть обоснованны. Автоматической дедупликации нет.

Источник: [BSL Language Server: InternetAccess](https://1c-syntax.github.io/bsl-language-server/diagnostics/InternetAccess/).
