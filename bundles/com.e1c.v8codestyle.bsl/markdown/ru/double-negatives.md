# Двойные отрицания

Двойное отрицание затрудняет чтение условий. Проверка находит `НЕ`, применённое
непосредственно к неравенству `<>` или к другому `НЕ`, через AST EDT.

## Неправильно

```bsl
Если Не Значение <> Неопределено Тогда
КонецЕсли;
Результат = Не (Не Признак);
```

## Правильно

```bsl
Если Значение = Неопределено Тогда
КонецЕсли;
Результат = Признак;
```

`Не Значение = Неопределено` и отрицание составного условия
`Не (А <> 0 И Б = 5)` не помечаются, как в LS. Строки и комментарии
не анализируются. Неполные выражения с ошибками разбора пропускаются:
EDT сама диагностирует `Не Не Признак` без скобок как ошибку синтаксиса.
Проверяются тела процедур и функций; код уровня модуля вне области проверки.

Быстрое исправление не предлагается: изменение условия требует решения автора.
