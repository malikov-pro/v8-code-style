# Лишний код в процедуре переопределяемого общего модуля

Проверяет, что процедура переопределяемого общего модуля (в имени содержится
**«Переопределяемый»/«Override»**, без учёта регистра), переопределяющая метод
с тем же именем другого общего модуля, состоит только из вызовов
переопределяемого метода: каждый оператор имеет вид
`<ИмяМодуля>.<ИмяПроцедуры>(...)`. Присваивания, условия, циклы и локальные
вызовы — лишний код: переопределяемая процедура должна сводиться к вызову
оригинала. Одно замечание на процедуру — по первому лишнему оператору.

Распознаются формы вызова из алгоритма АПК: прямой вызов
`Модуль.Метод(...)`, неявный вызов
`ОбщегоНазначения.ОбщийМодуль("Модуль").Метод(...)` (англ.
`Common.CommonModule("Module").Method(...)`) и вызов через переменную, которой
присвоен `ОбщегоНазначения.ОбщийМодуль("Модуль")` (сам оператор присваивания
считается лишним кодом, как в АПК). Код между комментариями
«// _Демо начало примера» и «// _Демо конец примера» не проверяется.

Упрощение против алгоритма АПК: процедура проверяется, только если существует
«парный» метод — метод с тем же именем в другом общем модуле конфигурации;
фильтр подсистем АПК не воспроизводится. Устаревшие процедуры не проверяются,
как в АПК. Заимствованные (adopted) общие модули проектов-расширений не
проверяются. Проверка выключена по умолчанию — включайте её для конфигураций,
развиваемых поверх иерархии библиотек.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс

Процедура ПередЗаписью(Объект, ПараметрыЗаписи) Экспорт

    // Лишний код: дополнительная логика в переопределяемой процедуре
    ПараметрыЗаписи.Вставить("Изменен", Истина);
    БазовыйМодуль.ПередЗаписью(Объект, ПараметрыЗаписи);

КонецПроцедуры

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

Процедура ПередЗаписью(Объект, ПараметрыЗаписи) Экспорт

    БазовыйМодуль.ПередЗаписью(Объект, ПараметрыЗаписи);

КонецПроцедуры

#КонецОбласти
```
