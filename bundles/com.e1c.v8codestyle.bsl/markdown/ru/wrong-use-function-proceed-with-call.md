# Некорректное использование функции ПродолжитьВызов()

`ПродолжитьВызов()` (`ProceedWithCall()`) продолжает выполнение оригинального
метода расширения. Точка вызова есть только в методе с аннотацией
`&Вместо`/`&Around`; в любом другом месте вызов падает во время выполнения.

`&ИзменениеИКонтроль`/`&ChangeAndValidate` — аннотация для метода, в котором
оригинал продолжается автоматически (платформа 8.3.16+). Методы с этой
аннотацией в текущей версии проверки пропускаются: EDT не сохраняет маркеры
внутри них (решение 16.11, отклонение от BSL Language Server зафиксировано).

Проверка сообщает о глобальном вызове `ПродолжитьВызов`/`ProceedWithCall`, если
у enclosing-метода нет ровно одной аннотации `&Вместо`. Вызов вне метода не
проверяется — как в pinned BSL Language Server.

## Неправильно

```bsl
&После("МояФункция")
Процедура Расш_МояФункция()
	ПродолжитьВызов(); // ошибка времени выполнения: точки вызова нет
КонецПроцедуры
```

## Правильно

```bsl
&Вместо("МояФункция")
Функция Расш_МояФункция()
	Возврат ПродолжитьВызов();
КонецФункции
```
