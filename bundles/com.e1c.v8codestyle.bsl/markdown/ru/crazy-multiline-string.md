# Строка собрана из нескольких фрагментов

Включена по умолчанию, CODE_STYLE / MAJOR. Строка, разбитая продолжениями `|`
или записанная соседними литералами, плохо читается и легко ломается при
правке: потерянный `|` молча меняет значение.

Маркер покрывает литерал целиком. Проверка намеренно лексическая: она не
оценивает итоговый текст, только число фрагментов.
