# Аудит использования системной информации

Проверка конструкторов `СистемнаяИнформация` / `SystemInfo` для аудита безопасности.
Выключена по умолчанию, важность CRITICAL. Параметров и быстрого исправления нет.

Проверьте, нужны ли сведения об операционной системе и оборудовании и не попадают
ли они к недоверенным пользователям. Замечание указывает на место для аудита,
а не доказывает наличие уязвимости.

Проверяются явные конструкторы и динамический `Новый("СистемнаяИнформация")`
в методах и теле модуля. Семантика соответствует pinned BSL Language Server:
используется первый строковый литерал первого аргумента, пробелы по краям
значения удаляются. Поэтому `Новый("SystemInfo" + Суффикс)` тоже отмечается;
скобки вокруг строки и переменное имя типа не вычисляются. Выделяется всё
выражение конструктора. Имена сопоставляются без учёта регистра на RU/EN.

Источник: [BSL Language Server: UseSystemInformation](https://1c-syntax.github.io/bsl-language-server/diagnostics/UseSystemInformation/).
