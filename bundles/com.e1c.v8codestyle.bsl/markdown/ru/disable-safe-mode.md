# Отключение безопасного режима

Проверяет глобальные УстановитьБезопасныйРежим/УстановитьОтключениеБезопасногоРежима (и английские имена) в методах и теле модуля. Допустим только явный безопасный флаг: Истина для первого вызова, Ложь для второго. Неизвестные флаги, отсутствие или лишние аргументы дают замечание. Методы объектов не проверяются. MAJOR/SECURITY, включена по умолчанию, без параметров и автоматического исправления. Это не проверка выполнения серверного кода в безопасном режиме.
