# Небезопасное булево использование БезопасныйРежим

БезопасныйРежим() может вернуть имя профиля безопасности, не только Булево. Неявное булево использование в Если/ИначеЕсли, логических выражениях или унарных операциях небезопасно. Сравнивайте явно, например БезопасныйРежим() <> Ложь. Методы объекта и явные сравнения исключены; обычное присваивание или аргумент вызова сами по себе не нарушение. CRITICAL/ERROR (отображение LS BLOCKER), включена по умолчанию, без параметров и автоматического исправления. Начиная с совместимости 8.3.1; это не проверка отключения безопасного режима.
