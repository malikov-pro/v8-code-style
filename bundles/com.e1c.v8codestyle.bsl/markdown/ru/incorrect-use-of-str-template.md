# Неверное использование СтрШаблон

Проверяет известные шаблоны глобального вызова СтрШаблон. Поддерживает `%1`–`%10`, номера в скобках (`%(1)45`), экранированные пары процентов, первый аргумент НСтр и литералы из предыдущих соседних операторов. Неизвестные динамические шаблоны и методы объектов пропускаются. Для каждого переданного аргумента нужна подстановка, для каждого номера подстановки — аргумент. Пустой строковый шаблон пропускается, как в зафиксированной версии LS. По умолчанию включена, CRITICAL/ERROR (BLOCKER LS отображён в CRITICAL). Параметров и автоматического исправления нет.

Предыдущие присваивания ищутся только в том же списке операторов, без перехода между ветвями и методами. Свойства сопоставляются по полному тексту обращения: в отличие от поиска по корневому имени в зафиксированной версии LS, `Объект.А` не получает шаблон из `Объект.Б`. Поиск текстовый, без индекса ссылок и полного анализа значений: он ищет предыдущие присваивания литералов, не отменяя их при промежуточном динамическом присваивании. Это ограничение и отличие поиска свойств не позволяют заявить полную эквивалентность LS.

```bsl
Результат = СтрШаблон("%1 %2", А); // нет второго аргумента
Результат = СтрШаблон("%11", А); // недопустимый номер
Результат = СтрШаблон("%(1)45", А); // допустимо
Результат = СтрШаблон("%%1"); // экранирование, аргумент не нужен
```
