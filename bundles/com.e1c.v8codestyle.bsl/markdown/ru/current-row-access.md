# Обращение к текущей строке динамического списка

Для доступа к полям строки используйте ТекущиеДанные вместо разыменования ТекущаяСтрока у таблицы формы, связанной с динамическим списком. Простое чтение ТекущаяСтрока, обычные табличные части, таблицы/деревья значений и неизвестные receiver не должны отмечаться. Нужна доказанная привязка receiver, не совпадение имени элемента формы.

Включена по умолчанию, MAJOR/PERFORMANCE, без параметров. Связанные позиции и автоисправление не добавляются. Полная эквивалентность LS не сертифицирована.

Отмечает токен ТекущаяСтрока перед обращением к свойству, вызовом метода или индексом. Привязка доказана разрешённым элементом формы, актуальным путём данных и единственным типом DynamicList у реквизита; устаревшего extInfo таблицы недостаточно. Изменение привязки, сегментов существующего пути и типа реквизита пересчитывает модуль без редактирования BSL. Алиасы элементов, составные типы, расширения и внешние формы не сертифицированы; неразрешённые receiver пропускаются. Это частичная реализация, не полный движок вывода типов форм.
