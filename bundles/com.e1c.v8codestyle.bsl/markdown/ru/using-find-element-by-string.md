# Поиск элемента по литералу

Проверяет методы объекта НайтиПоНаименованию/Коду/Номеру (RU/EN). Первый аргумент подозрителен, если пуст или начинается строковым/десятичным токеном, как в LS. Переменные, отрицательные числа и литералы в скобках исключены. Подстановка констант и уникальность поиска по метаданным не анализируются. Отсутствие аргументов безопасно трактуется как пустой аргумент. MAJOR/CODE_STYLE, включена по умолчанию, без параметров и автоматического исправления. Не заменяет типизированную диагностику UnsafeFindByCode.
