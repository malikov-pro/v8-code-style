# Не все пути функции возвращают значение

Функция содержит «Возврат», но может дойти до конца тела без явного возврата — на этом пути результатом будет неявное «Неопределено». Порт диагностики BSL Language Server AllFunctionPathMustHaveReturn: строится граф потока управления по телу метода, defaults MAJOR/CODE_STYLE, включена.

Функция без единого «Возврат» здесь намеренно не проверяется — она остаётся более простой проверке `function-should-have-return` (такая же дедупликация, как в LS). Функции с незавершённым синтаксисом (без «КонецФункции») и фрагменты с синтаксическими ошибками пропускаются. Бесконечный цикл «Пока Истина» не создаёт провального выхода. Ветви препроцессора консервативно считаются все возможными.

Параметры (умолчания LS): `loopsExecutedAtLeastOnce=true` — тело цикла считается выполненным, выход из цикла по условию не считается провалом; `ignoreMissingElseOnExit=false` — цепочка «ИначеЕсли» без «Иначе», доходящая до конца функции, помечается.

Маркер ставится на имя функции. Related-позиции диагностики LS в этой версии не переносятся. Граф строится по методу во время валидации; кэша между валидациями нет.
