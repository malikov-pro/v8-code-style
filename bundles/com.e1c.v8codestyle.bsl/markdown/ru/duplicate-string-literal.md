# Повторяющийся строковый литерал

Группирует исходные строковые литералы с кавычками, сохраняя пробелы внутри строк. По умолчанию: `allowedNumberCopies=2`, `analyzeFile=false`, `caseSensitive=false`, `minTextLength=5` с кавычками. Лимит повторений меньше 1 заменяется на 2; минимальная длина ограничена снизу 5, как в LS. Без анализа файла методы (включая значения параметров по умолчанию) и блоки тела модуля проверяются отдельно; анализ файла объединяет весь модуль. На избыточную группу ставится одно замечание на первый литерал. MINOR/WARNING, включена по умолчанию; без автоматического исправления. Связанные диапазоны повторений LS не переносятся.
