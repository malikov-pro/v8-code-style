# Блокировка данных создана, но не заблокирована

Проверяет, что блокировка данных, созданная оператором «Новый БлокировкаДанных» и заполненная элементами через метод «Добавить()», где-то в том же методе блокируется вызовом метода «Заблокировать()». Созданная, но ни разу не заблокированная блокировка не защищает данные от конкурентного изменения.

Отслеживание лексическое, в пределах одного метода: если блокировка передана в другой метод, который её блокирует, замечание всё равно выдаётся. Случаи, когда конструктор не присваивается локальной переменной, не отслеживаются. Требование вызывать «Заблокировать()» в попытке проверяется отдельной проверкой «Метод Заблокировать() вне блока Попытка-Исключение» (lock-out-of-try).

## Неправильно

```bsl
Процедура ЗаписатьДокументы()

	БлокировкаДанных = Новый БлокировкаДанных;
	ЭлементБлокировкиДанных = БлокировкаДанных.Добавить("Документ.ПриходнаяНакладная");
	ЭлементБлокировкиДанных.Режим = РежимБлокировкиДанных.Исключительный;

КонецПроцедуры
```

## Правильно

```bsl
Процедура ЗаписатьДокументы()

	БлокировкаДанных = Новый БлокировкаДанных;
	ЭлементБлокировкиДанных = БлокировкаДанных.Добавить("Документ.ПриходнаяНакладная");
	ЭлементБлокировкиДанных.Режим = РежимБлокировкиДанных.Исключительный;
	БлокировкаДанных.Заблокировать();

КонецПроцедуры
```
