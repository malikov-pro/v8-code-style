# Унарный плюс в конкатенации

Находит унарный плюс, перед которым предыдущий значимый токен — ещё один плюс. Пробелы и комментарии пропускаются. Исключение — числовой литерал после унарного плюса. Вывод строкового типа не требуется: это соответствует алгоритму зафиксированной версии BSL LS. Проверяются методы и тело модуля. Замечание выделяет только унарный плюс. По умолчанию включена, CRITICAL/ERROR (BLOCKER LS отображён в CRITICAL); параметров и автоматического исправления нет.

```bsl
Результат = "Первая" + + "Вторая"; // замечание на втором плюсе
Результат = А + + Б;              // без вывода типа
Результат = А + + 5;              // числовое исключение
Результат = А + (+ Б);            // предыдущий токен — скобка, не плюс
```
