# Метаданные объекта получаются через свойство глобального контекста Метаданные

Проверяет, что метаданные объекта получаются методом **Метаданные()** самого объекта, а не обращением к свойству глобального контекста **Метаданные**. Обращение через глобальное свойство (например, `Метаданные.Справочники[Имя]`, `Метаданные.Документы.НайтиПоКоду(...)`) существенно медленнее.

Исключение — метод `НайтиПоТипу`: когда тип объекта метаданных заранее неизвестен, используется `Метаданные.НайтиПоТипу(...)`.

## Неправильно

```bsl
Справочник = Метаданные.Справочники[ИмяСправочника];
Элемент = Метаданные.Документы.НайтиПоКоду(КодДокумента);
```

## Правильно

```bsl
Справочник = СправочникОбъект.Метаданные();
Элемент = СсылкаДокумента.Метаданные();
// Тип заранее неизвестен:
Имя = Метаданные.НайтиПоТипу(ТипЗнч(Ссылка)).ПолноеИмя();
```
