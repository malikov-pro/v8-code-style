# В сообщениях не употребляются местоимения «Вы», «Вас» и пр.

Проверяет, что тексты сообщений для пользователя (строковые литералы) не содержат местоимений **Вы**, **Вас**, **Вам**, **Вами**, **Ваш**: сообщения составляются в форме безличного предложения. Фиксируются только цельные слова; «Вашего» или «Выполнить» не помечаются. Комментарии не проверяются. Одно замечание на строку вхождения.

## Неправильно

```bsl
Сообщение = "У Вас недостаточно прав для выполнения обработки";
```

## Правильно

```bsl
Сообщение = "Недостаточно прав для выполнения обработки";
```
