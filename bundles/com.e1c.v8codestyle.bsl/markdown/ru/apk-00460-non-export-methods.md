# Неэкспортный метод в переопределяемом общем модуле

Проверяет, что переопределяемый общий модуль (в имени содержится
**«Переопределяемый»**/«Override», без учёта регистра) не содержит неэкспортных
методов: переопределяющий модуль может содержать только экспортные методы,
переопределяющие методы библиотеки. Каждый неэкспортный метод помечается
отдельным замечанием.

Неэкспортный метод переопределяемого модуля недоступен для вызывающего
механизма и никогда не будет выполнен.

Заимствованные (adopted) общие модули проектов-расширений не проверяются.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс

// Неэкспортный метод никогда не будет вызван
Процедура ДозаполнитьНаборыЗаписей(НаборыЗаписей)
    ...
КонецПроцедуры

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

Процедура ДозаполнитьНаборыЗаписей(НаборыЗаписей) Экспорт
    ...
КонецПроцедуры

#КонецОбласти
```
