# Использование модальных окон

Проверяет использование модальных методов (Вопрос, ОткрытьФормуМодально, ОткрытьЗначение, Предупреждение, ВвестиДату, ВвестиЗначение, ВвестиСтроку, ВвестиЧисло): они не работают в веб-клиенте. Используйте асинхронные аналоги (ПоказатьВопрос, ОткрытьФорму, ПоказатьЗначение и т.д.), как в BSL LS. Проверка не имеет quick fix: асинхронные аналоги меняют структуру кода.
