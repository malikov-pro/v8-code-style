# Использование синхронных вызовов

Проверяет использование синхронных методов глобального контекста в клиентских модулях, когда конфигурация ограничивает синхронные вызовы: синхронные вызовы не работают в веб-клиенте. Вместо синхронного метода используйте его асинхронный аналог.

Проверяемые методы: `Вопрос`, `ОткрытьФормуМодально`, `ОткрытьЗначение`, `Предупреждение`, `ВвестиДату`, `ВвестиЗначение`, `ВвестиСтроку`, `ВвестиЧисло`, `УстановитьВнешнююКомпоненту`, `УстановитьРасширениеРаботыСФайлами`, `УстановитьРасширениеРаботыСКриптографией`, `ПодключитьРасширениеРаботыСКриптографией`, `ПодключитьРасширениеРаботыСФайлами`, `ПоместитьФайл`, `КопироватьФайл`, `ПереместитьФайл`, `НайтиФайлы`, `УдалитьФайлы`, `СоздатьКаталог`, `КаталогВременныхФайлов`, `КаталогДокументов`, `РабочийКаталогДанныхПользователя`, `ПолучитьФайлы`, `ПоместитьФайлы`, `ЗапроситьРазрешениеПользователя`, `ЗапуститьПриложение`.

Проверка не фиксирует:

- строго серверные модули (модули объектов, наборов записей, сеанса и пр.);
- вызовы в методах с директивами компиляции `&НаСервере` и `&НаСервереБезКонтекста`;
- конфигурации, где использование синхронных вызовов разрешено (свойство конфигурации «Режим использования синхронных вызовов расширений платформы и внешних компонент» = Использовать).

## Неправильно

```bsl
&НаКлиенте
Процедура ЗадатьВопросПользователю()
    Если Вопрос("Продолжить?", РежимДиалогаВопрос.ДаНет) = КодВозвратаДиалога.Да Тогда
        // продолжить
    КонецЕсли;
КонецПроцедуры
```

## Правильно

```bsl
&НаКлиенте
Процедура ЗадатьВопросПользователю()
    Оповещение = Новый ОписаниеОповещения("ПослеЗакрытияВопроса", ЭтотОбъект);
    ПоказатьВопрос(Оповещение, "Продолжить?", РежимДиалогаВопрос.ДаНет);
КонецПроцедуры
```

Проверка не имеет quick fix: асинхронные аналоги меняют структуру кода (обработчик оповещения).
