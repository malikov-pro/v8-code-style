# Несколько директив компиляции

У метода или переменной модуля может быть только одна директива компиляции:
`&НаКлиенте`, `&НаСервере`, `&НаСервереБезКонтекста`,
`&НаКлиентеНаСервереБезКонтекста`. Вторая директива противоречит первой,
платформа отвергает такой метод или молча выбирает одну из них.

Аннотации расширений (`&Вместо`, `&Перед`, `&После`, `&ИзменениеИКонтроль`) —
другой вид прагмы: они содержат имя переопределяемого метода и не считаются.
Переменные модуля и методы проверяются раздельно, поэтому проверки структуры
модуля не дублируются.

## Неправильно

```bsl
&НаСервере
&НаСервереБезКонтекста
Процедура ЗаполнитьДокумент()
КонецПроцедуры
```

## Правильно

```bsl
&НаСервереБезКонтекста
Процедура ЗаполнитьДокумент()
КонецПроцедуры
```
