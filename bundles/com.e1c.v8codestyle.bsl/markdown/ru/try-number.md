# Преобразование в число внутри Попытки

Находит глобальные вызовы Число / Number в теле Попытки, включая вложенные блоки. Прямой вызов в Исключении исключён, если оно само не внутри внешней Попытки. Методы объекта пропускаются. Типы и поток данных не анализируются. MAJOR/CODE_STYLE, включена по умолчанию; без параметров и автоматического исправления. Как в LS, имена сопоставляются синтаксически, пользовательские одноимённые методы отдельно не разрешаются.
