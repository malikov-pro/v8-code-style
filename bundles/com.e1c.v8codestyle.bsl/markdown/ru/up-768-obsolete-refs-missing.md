# Устаревшая процедура (функция) ссылается на несуществующую процедуру (функцию)

Устаревшая процедура (функция) — помеченная «Устарела.»/«Deprecated.»,
размещённая в области «УстаревшиеПроцедурыИФункции» либо имеющая признак
устаревания в контексте модуля — должна ссылаться на **существующую** замену.
Проверка разбирает комментарий-описание над объявлением метода и разрешает
каждую отсылку «см. Модуль.ИмяМетода» (в любом регистре; распознаётся и
английское `see`; между «см.» и именем допускается одно слово — «см. также …»).
Если общий модуль или целевой метод не найдены в конфигурации — регистрируется
замечание: отсылка ведёт в никуда и вводит разработчиков в заблуждение.

Ссылка на существующий, но устаревший метод помечается отдельной проверкой
`up-769-obsolete-refs-obsolete`.

Упрощения: цели ищутся по общим модулям конфигурации; проверяются только общие
модули; ссылки на методы объектных модулей и глобальный контекст не
разрешаются.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс

// Устарела. Следует использовать новую (см. CommonModule.НесуществующаяФункция).
Функция СтараяФункция() Экспорт

	Возврат Истина;

КонецФункции

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

// Устарела. Следует использовать новую (см. CommonModule.АктуальнаяФункция).
Функция СтараяФункция() Экспорт

	Возврат Истина;

КонецФункции

// Актуальная функция-замена.
Функция АктуальнаяФункция() Экспорт

	Возврат Истина;

КонецФункции

#КонецОбласти
```
