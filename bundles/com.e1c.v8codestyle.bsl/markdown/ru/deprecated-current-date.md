# Использование устаревшего метода «ТекущаяДата»

Проверяет использование устаревшего метода «ТекущаяДата»: текущее время может отличаться на клиенте и сервере, что приводит к непредсказуемому поведению. Используйте «ТекущаяДатаСеанса» — часовой пояс сеанса определён однозначно.

Эта проверка **замещает** «ТекущаяДата» в дефолтном списке `use-non-recommended-method` (грубая проверка больше не сообщает о нём по умолчанию) и поднимает серьёзность: MAJOR/ERROR вместо MINOR/CODE_STYLE.

Quick fix не предусмотрен: меняется семантика времени (сеанс против клиент/сервер) — решение за пользователем.

## Неправильно

```bsl
Момент = ТекущаяДата();
```

## Правильно

```bsl
Момент = ТекущаяДатаСеанса();
```
