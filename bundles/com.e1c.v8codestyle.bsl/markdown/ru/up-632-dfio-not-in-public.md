# Область «ДляВызоваИзДругихПодсистем» не входит в область «ПрограммныйИнтерфейс»

По статье 644 стандарта 1С (п. 2.2) область
**«ДляВызоваИзДругихПодсистем»** (англ. **«InterfaceImplementation»**)
размещается внутри области **«ПрограммныйИнтерфейс»** (англ.
**«Public»**). Верхнеуровневая область или область, вложенная в любую
другую область, помечается замечанием на имя области.

Распознаются канонические русское и английское имена области, регистр
не учитывается. Проверяются все типы модулей; заимствованные (adopted)
модули проектов-расширений не проверяются.

## Неправильно

```bsl
#Область ДляВызоваИзДругихПодсистем
// верхнеуровневая область: нет области «ПрограммныйИнтерфейс»
...
#КонецОбласти
```

```bsl
#Область СлужебныеПроцедурыИФункции

#Область ДляВызоваИзДругихПодсистем
// вложена в служебную область, а не в «ПрограммныйИнтерфейс»
...
#КонецОбласти

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

#Область ДляВызоваИзДругихПодсистем
...
#КонецОбласти

#КонецОбласти
```
