# Устаревшая проверка АвтоТест

Opt-in аудит CODE_STYLE/MINOR, по умолчанию выключен. Контракт — диагностика
BSL Language Server ExcessiveAutoTestCheck. Автоисправления нет: удаление условия
требует решения с учётом проекта.

Проверяются модули форм, объектов, наборов записей и общие модули, включая
тело модуля. Модули менеджера, сеанса, команд и остальные типы исключены.
Выделяется весь оператор Если, включая Иначе/ИначеЕсли при их наличии.
Анализируется только первая ветвь Если: в ней должен быть ровно один Возврат,
со значением или без. Комментарии не считаются операторами.

Сопоставление лексическое, без учёта регистра, по суффиксу значимых токенов
условия: `.Свойство("АвтоТест")`, `.Property("AutoTest")`, `="АвтоТест"`
или `="AutoTest"`. Смешанные `.Property("АвтоТест")` и
`.Свойство("AutoTest")` намеренно не добавлены. Внешние скобки могут исключить
совпадение; Не и предшествующий операнд Или не мешают совпадению суффикса.
Проверка не доказывает тип владельца или реальный контекст автотестирования.
Учитывайте эти границы pinned LS при включении аудита.

Источник: [BSL Language Server: ExcessiveAutoTestCheck](https://1c-syntax.github.io/bsl-language-server/diagnostics/ExcessiveAutoTestCheck/).
