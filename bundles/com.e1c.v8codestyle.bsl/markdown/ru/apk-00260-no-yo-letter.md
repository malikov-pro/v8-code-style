# Буква «ё» в коде модулей

Проверяет, что буква **ё** (в любом регистре) не используется в коде модуля: в идентификаторах и строковых литералах. Каждое вхождение помечается отдельным замечанием. Комментарии не проверяются — в них «ё» допустима.

## Неправильно

```bsl
Процедура ПередЗаписью(Отказ, ПараметрыЗаписи)
    
    Сообщение = "Ёлка возле дома";
    Ёлочка = Сообщение;
    
КонецПроцедуры
```

## Правильно

```bsl
// Комментарий с буквой ё допустим — комментарии не проверяются
Процедура ПередЗаписью(Отказ, ПараметрыЗаписи)
    
    Сообщение = "Елка возле дома";
    Елочка = Сообщение;
    
КонецПроцедуры
```

## См. также

- [Стандарт 598. Отказ от использования буквы «ё» в текстах модулей](https://its.1c.ru/db/v8std#content:598:hdoc)
- Перенос проверки АПК `АПК_00260`.
- Комментарии исключены из проверки: правило относится только к коду.
