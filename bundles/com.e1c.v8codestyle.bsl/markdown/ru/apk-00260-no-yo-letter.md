# Буква «ё» в текстах модулей

Проверяет, что буква **ё** (в любом регистре) не используется в текстах модулей: в коде, строковых литералах и комментариях. Каждое вхождение помечается отдельным замечанием.

## Неправильно

```bsl
// Слово «ещё» не должно писаться через «ё»
Процедура ПередЗаписью(Отказ, ПараметрыЗаписи)
    
    Сообщение = "Свежие номера";
    
КонецПроцедуры
```

## Правильно

```bsl
// Слово «ещё» не должно писаться через «ё»
Процедура ПередЗаписью(Отказ, ПараметрыЗаписи)
    
    Сообщение = "Свежие номера";
    
КонецПроцедуры
```
