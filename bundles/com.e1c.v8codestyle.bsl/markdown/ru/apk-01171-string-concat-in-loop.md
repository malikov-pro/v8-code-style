# Массовая конкатенация строк в цикле

Проверяет аккумуляцию строки в цикле через конкатенацию: переменная
присваивается сама себе с наращиванием («Переменная = Переменная + ...»).
Каждая такая конкатенация создаёт новую строку, и на больших объёмах данных
это медленно и расходует память.

При массовых операциях (ориентир стандарта — от 1000 конкатенаций) собирайте
части в массив и объединяйте методом `СтрСоединить()` (разбиение —
`СтрРазделить()`). Одно замечание на цикл. Числовые счётчики
(`Счетчик = Счетчик + 1`) не помечаются.

## Неправильно

```bsl
ИзвлеченныйТекст = "";
Для НомерКолонки = 1 По Макет.ШиринаТаблицы Цикл
    ИзвлеченныйТекст = ИзвлеченныйТекст + Символы.ПС + ТекстОбласти;
КонецЦикла;
```

## Правильно

```bsl
ИзвлеченныеТексты = Новый Массив;
Для НомерКолонки = 1 По Макет.ШиринаТаблицы Цикл
    ИзвлеченныеТексты.Добавить(ТекстОбласти);
КонецЦикла;
ИзвлеченныйТекст = СтрСоединить(ИзвлеченныеТексты, Символы.ПС);
```

## Ограничения

Правило АПК считает конкатенации в рантайме и срабатывает от 1000 операций.
Статическая проверка не может посчитать итерации, поэтому помечает сам
шаблон аккумуляции в цикле; типы не вычисляются, поэтому аккумуляция
с переменными и вызовами функций может быть помечена и для числовых
накоплений.
