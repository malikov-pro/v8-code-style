# Использование устаревшего метода «Найти»

Проверяет использование устаревшего глобального метода «Найти». Используйте «СтрНайти»: у неё ясная семантика аргументов и больше возможностей поиска.

Методы объекта (`Объект.Найти`) не проверяются — как в BSL Language Server. Эта проверка **замещает** «Найти» в дефолтном списке `use-non-recommended-method` (грубая проверка больше не сообщает о нём по умолчанию).

Quick fix не предусмотрен: у «Найти» и «СтрНайти» разный порядок аргументов.

## Неправильно

```bsl
Позиция = Найти("Привет, мир", "мир");
```

## Правильно

```bsl
Позиция = СтрНайти("Привет, мир", "мир");
```
