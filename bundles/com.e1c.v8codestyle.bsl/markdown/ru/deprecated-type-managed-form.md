# Устаревшее имя типа управляемой формы

Включена по умолчанию, CODE_STYLE / TRIVIAL. В режиме совместимости 8.3.14
и ниже `Тип("УправляемаяФорма")` / `Type("ManagedForm")` задаёт тип управляемой
формы устаревшим псевдонимом.

Проверка следует области pinned LS: сообщается только глобальный вызов
`Тип`/`Type` с единственным устаревшим строковым аргументом. Маркер покрывает
весь вызов (LS якорит список параметров). Устаревшее имя — тихий псевдоним;
автоматической замены в v1 нет.
