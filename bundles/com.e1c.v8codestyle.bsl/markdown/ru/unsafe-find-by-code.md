# Небезопасный поиск по коду

Проверяет НайтиПоКоду / FindByCode менеджера справочника или плана по метаданным: отключённый КонтрольУникальности или серии кодов не по всему объекту делают поиск небезопасным. Это не using-find-element-by-string: аргумент не обязательно литерал. Неизвестный receiver нельзя угадывать по имени.

Включена по умолчанию, MAJOR/CODE_STYLE, без параметров и автоисправления. Только прямые обращения через Справочники / ПланыСчетов / ПланыВидовХарактеристик (RU/EN), как в pinned LS MdoRefBuilder; переменные-алиасы менеджера исключены. Принадлежность метаданным доказана разрешённым типом, не угадывается по имени. Изменение только метаданных пересчитывает индексированных потребителей того же проекта без изменения их исходника. Межпроектный scope и union receivers не сертифицированы. Связанных позиций нет. Полная эквивалентность pinned LS не сертифицирована.
