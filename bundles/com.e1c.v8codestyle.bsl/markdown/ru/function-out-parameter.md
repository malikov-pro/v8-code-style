# Выходные параметры функций

Отмечает первое прямое присваивание каждому параметру функции по ссылке, включая вложенные операторы. Параметры Знач, процедуры, изменения свойств/индексов и вызовы, способные изменить аргумент, не проверяются. Выделяется цель присваивания. MAJOR/WARNING, по умолчанию выключена как в LS; без параметров и автоматического исправления. В отличие от RewriteMethodParameter, речь о результате функции через параметр по ссылке, а не перезаписи входного значения до чтения. Достижимость операторов не анализируется.
