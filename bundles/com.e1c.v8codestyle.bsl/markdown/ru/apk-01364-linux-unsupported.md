# Методы и объекты, не поддерживаемые ОС Linux

Ряд методов и объектов платформы опирается на технологии Windows (COM, OLE) или особенности управления окнами ОС и не работает в Linux. Используйте кроссплатформенные механизмы (статья 723 стандарта):

- вместо COM (`COMОбъект`) — файловый обмен, web/HTTP-сервисы или сервер администрирования;
- внешние компоненты разрабатывайте по технологии Native API (`ПодключитьВнешнююКомпоненту` с `ТипВнешнейКомпоненты.Native`);
- вместо объекта `Почта` — `ИнтернетПочта` или внешняя компонента с поддержкой почтовых клиентов Linux;
- объект `ИзвлечениеТекста`, методы `Файл.УстановитьНевидимость`, `Файл.УстановитьНевидимостьАсинх`, `КлиентскоеПриложение.ПолучитьОтображениеЗаголовкаОС`, `КлиентскоеПриложение.УстановитьОтображениеЗаголовкаОС` в Linux не поддерживаются.

Проверка выполняется по полному тексту модуля, включая комментарии и строковые литералы, как в исходном алгоритме АПК, и ставит замечание на каждое вхождение (без учёта регистра, русские и английские имена):

- `.УстановитьНевидимость(` (`.SetHidden(`), `.УстановитьНевидимостьАсинх(` (`.SetHiddenAsync(`)
- `.ПолучитьОтображениеЗаголовкаОС(` (`.GetOSCaptionRepresentation(`), `.УстановитьОтображениеЗаголовкаОС(` (`.SetOSCaptionRepresentation(`)
- `ЗагрузитьВнешнююКомпоненту(` (`LoadAddIn(`), `НачатьПодключениеВнешнейКомпоненты(` (`BeginAttachingAddIn(`), `ПодключитьВнешнююКомпоненту(` (`AttachAddIn(`), `ПодключитьВнешнююКомпонентуАсинх(` (`AttachAddInAsync(`)
- `ТипВнешнейКомпоненты.COM` (`AddInType.COM`)
- `Новый Почта` (`New Mail`), `Новый ИзвлечениеТекста` (`New TextExtraction`), `Новый COMОбъект` (`New COMObject`)

Проверка по умолчанию выключена: предусловие АПК «правило выполняется только в ОС Linux» (`ЭтоLinux()`) статически не воспроизводится — включайте её для решений, которые должны работать в Linux.

## Неправильно

```bsl
Процедура ПодключитьКомпонентуОбмена()

	ПодключитьВнешнююКомпоненту("Обмен", "Тип", ТипВнешнейКомпоненты.COM); // COM недоступен в Linux
	Почтовик = Новый Почта;                                                // объект Почта не поддерживается в Linux

КонецПроцедуры
```

## Правильно

```bsl
Процедура ПодключитьКомпонентуОбмена()

	ПодключитьВнешнююКомпоненту("Обмен", "Тип", ТипВнешнейКомпоненты.Native); // Native API поддерживает Linux
	// почта отправляется через ИнтернетПочта или внешнюю компоненту с почтовым клиентом Linux

КонецПроцедуры
```
