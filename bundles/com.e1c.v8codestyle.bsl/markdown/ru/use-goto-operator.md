# Используется оператор Перейти

В коде на встроенном языке не рекомендуется использовать оператор Перейти, 
так как необдуманное использование данного оператора приводит к получению запутанных, 
плохо структурированных модулей, по тексту которых затруднительно понять порядок 
исполнения и взаимозависимость фрагментов. Вместо оператора Перейти рекомендуется использовать 
другие конструкции встроенного языка.

По политике проекта Перейти считается блокирующим нарушением: важность проверки
по умолчанию — BLOCKER. Проверка отмечает операторы Перейти и метки. Явные
настройки важности проекта не перезаписываются. BLOCKER — важность замечания,
а не автоматическая остановка валидации или сборки.

Будущие CFG-проверки путей возврата и недостижимости будут пропускать метод или
анализируемый блок тела модуля с Перейти, а не моделировать переходы по меткам
или делать ненадёжные выводы из линейного порядка операторов. Это согласованное
отличие от BSL LS, чей CFG обрабатывает Перейти. Остальные проверки работают;
эта политика не означает, что CFG и механизм пропуска уже реализованы.

## Неправильно

```bsl
Если ПланВидовРасчета = Объект.ПланВидовРасчета Тогда
  
  Перейти ~ПланВидовРасчета;
  
КонецЕсли;
```

## Правильно

```bsl
Если ПланВидовРасчета = Объект.ПланВидовРасчета Тогда
  
  ОбработатьПланВидовРасчета();
  
КонецЕсли;
```
