# Параметры вызываемого метода не совпадают с параметрами переопределяемой процедуры

Проверяет, что вызов переопределяемого метода из процедуры переопределяемого
общего модуля (в имени содержится **«Переопределяемый»/«Override»**, без учёта
регистра) передаёт все параметры переопределяемой процедуры в том же порядке:
сравниваются имена и количество параметров по позициям (типы в 1С не
декларируются). Каждый вызов с несовпадающим количеством, порядком или именами
параметров помечается отдельным замечанием.

Распознаются формы вызова из алгоритма АПК: прямой вызов `Модуль.Метод(...)`,
неявный вызов `ОбщегоНазначения.ОбщийМодуль("Модуль").Метод(...)` (англ.
`Common.CommonModule("Module").Method(...)`) и вызов через переменную, которой
присвоен `ОбщегоНазначения.ОбщийМодуль("Модуль")`. Код между комментариями
«// _Демо начало примера» и «// _Демо конец примера» не проверяется.

Упрощение против алгоритма АПК: процедура проверяется, только если существует
«парный» метод — метод с тем же именем в другом общем модуле конфигурации
(глобальный поиск по IV8ProjectManager); фильтр подсистем АПК не
воспроизводится. Устаревшие процедуры не проверяются, как в АПК.
Заимствованные (adopted) общие модули проектов-расширений не проверяются.
Проверка выключена по умолчанию — включайте её для конфигураций, развиваемых
поверх иерархии библиотек.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс

Процедура ПередЗаписью(Объект, ПараметрыЗаписи) Экспорт

    // Не передан второй параметр
    БазовыйМодуль.ПередЗаписью(Объект);

КонецПроцедуры

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

Процедура ПередЗаписью(Объект, ПараметрыЗаписи) Экспорт

    БазовыйМодуль.ПередЗаписью(Объект, ПараметрыЗаписи);

КонецПроцедуры

#КонецОбласти
```
