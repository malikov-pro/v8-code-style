# Одно выражение в одной строке

Проверяет, что строка содержит один оператор. Несколько операторов в одной строке затрудняют чтение кода и отладку (нельзя поставить точку останова на конкретный оператор).

Препроцессорные инструкции и пустые операторы (`;`) не учитываются; замечание ставится на каждый оператор строки — как в BSL Language Server. Quick fix переносит оператор на новую строку (для первого оператора строки фикс недоступен).

## Неправильно

```bsl
Процедура Заполнить()
	А = 1; Б = 2;
КонецПроцедуры
```

## Правильно

```bsl
Процедура Заполнить()
	А = 1;
	Б = 2;
КонецПроцедуры
```
