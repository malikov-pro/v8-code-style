# Использование методов глобального контекста для работы с файлами

В решениях на БСП для сценариев работы с файлами применяйте программный интерфейс **ФайловаяСистемаКлиент**, а не методы глобального контекста. Проверка фиксирует вызовы глобальных методов:

- «ПоместитьФайл» / «НачатьПомещениеФайла» — вместо них «ФайловаяСистемаКлиент.ЗагрузитьФайл()» / «ЗагрузитьФайлы()»;
- «ПоместитьФайлы» / «НачатьПомещениеФайлов» — вместо них «ФайловаяСистемаКлиент.ЗагрузитьФайлы()»;
- «ПолучитьФайл» / «ПолучитьФайлы» / «НачатьПолучениеФайлов» — вместо них «ФайловаяСистемаКлиент.СохранитьФайл()» / «СохранитьФайлы()».

Также фиксируется вызов «Показать» у переменной, которой в методе присвоен «Новый ДиалогВыбораФайла» — вместо него «ФайловаяСистемаКлиент.ВыбратьКаталог()» и асинхронные аналоги. Отслеживание — на один уровень (переменная, присвоенная в том же методе), как в АПК.

Общие модули «ФайловаяСистемаКлиент» и «ФайловаяСистемаСлужебныйКлиент» не проверяются.

Проверка **выключена по умолчанию**: предусловие АПК «в решении есть подсистема ТехнологияСервиса/БСП» статически не воспроизводится, поэтому включайте её для решений на БСП.

## Неправильно

```bsl
ПоместитьФайл(АдресВХранилище, ИмяФайла, Истина);

Диалог = Новый ДиалогВыбораФайла(РежимДиалогаВыбораФайла.Открытие);
Если Диалог.Показать() Тогда
	ПутьКФайлу = Диалог.ВыбранныеФайлы[0];
КонецЕсли;
```

## Правильно

```bsl
ПараметрыЗагрузки = ФайловаяСистемаКлиент.ПараметрыЗагрузкиФайла();
ФайловаяСистемаКлиент.ЗагрузитьФайл(ПараметрыЗагрузки);
```
