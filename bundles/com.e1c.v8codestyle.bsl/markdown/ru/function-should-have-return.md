# Функция должна содержать возврат

Проверяет, что функция содержит хотя бы один оператор **Возврат**. Функция без «Возврат» неявно возвращает **Неопределено**, что обычно является ошибкой: такой метод должен вернуть значение либо быть переписан в процедуру. Платформа 1С этот случай не диагностирует.

## Неправильно

```bsl
Функция СуммаДоПредела(СуммаДокумента)
	
	Если СуммаДокумента > Предел Тогда
		Сообщить(СуммаДокумента);
	КонецЕсли;
	
КонецФункции
```

## Правильно

```bsl
Функция СуммаДоПредела(СуммаДокумента)
	
	Результат = 0;
	
	Если СуммаДокумента > Предел Тогда
		Сообщить(СуммаДокумента);
	Иначе
		Результат = СуммаДокумента;
	КонецЕсли;
	
	Возврат Результат;
	
КонецФункции
```
