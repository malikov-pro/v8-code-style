# У вызываемого метода нет комментария «См. Модуль.Процедура»

Проверяет, что у метода общего модуля библиотеки, вызываемого из
переопределяющей процедуры переопределяемого общего модуля (в имени содержится
**«Переопределяемый»/«Override»**, без учёта регистра), есть
комментарий-отсылка `См. <ПереопределяемыйМодуль>.<Процедура>.` над
объявлением (между комментарием и объявлением допускаются пустые строки).
После нормализации комментария (без «/», пробелов и переводов строк) текст
должен начинаться с `См.<Модуль>.<Метод>`; регистр «См.» и имён значим, как в
алгоритме АПК.

Распознаются формы вызова из алгоритма АПК: прямой вызов `Модуль.Метод(...)`,
неявный вызов `ОбщегоНазначения.ОбщийМодуль("Модуль").Метод(...)` (англ.
`Common.CommonModule("Module").Method(...)`) и вызов через переменную, которой
присвоен `ОбщегоНазначения.ОбщийМодуль("Модуль")`. Вызовы методов с именем,
отличным от имени переопределяемой процедуры, здесь не проверяются (см.
apk-00460-procedure-name-match).

Отклонения от алгоритма АПК: замечание регистрируется на переопределяющей
процедуре (в АПК — на вызываемом модуле; межресурсные маркеры проверки модуля
не используются); процедура проверяется, только если существует «парный»
метод — метод с тем же именем в другом общем модуле конфигурации (глобальный
поиск по IV8ProjectManager); фильтр подсистем АПК не воспроизводится.
Заимствованные (adopted) общие модули проектов-расширений не проверяются.
Проверка выключена по умолчанию — включайте её для конфигураций, развиваемых
поверх иерархии библиотек.

## Неправильно

```bsl
#Область ПрограммныйИнтерфейс

// У метода библиотеки нет комментария-отсылки
Процедура ПередЗаписью(Объект, ПараметрыЗаписи) Экспорт

КонецПроцедуры

#КонецОбласти
```

## Правильно

```bsl
#Область ПрограммныйИнтерфейс

// См. МойМодульПереопределяемый.ПередЗаписью.
Процедура ПередЗаписью(Объект, ПараметрыЗаписи) Экспорт

КонецПроцедуры

#КонецОбласти
```
