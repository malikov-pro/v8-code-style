# Пустой блок кода

Проверяет, что блоки кода условий, циклов и Попытки не пусты. Пустой блок — признак забытой реализации или удалённого содержимого: блок следует наполнить или удалить.

Не проверяются: тела методов (см. проверку «Пустой метод»), блоки «Исключение» (см. проверку «Пустое исключение») и файловый блок модуля.

Параметр **Считать комментарии кодом** (`commentAsCode`, по умолчанию false): комментарий должен находиться в проверяемой секции. Комментарий в другой ветви или Исключении не заполняет пустой блок; похожий текст внутри строкового литерала не считается комментарием.

Основной диапазон следует правилу терминалов родителя LS: от первого до последнего собственного терминала заголовка на его последней строке, без завершающего комментария. В многострочном заголовке может выделяться только Тогда/Цикл либо По/Из до Цикл у Для. Если пустой цикл закрывается на той же строке, КонецЦикла включается; КонецЕсли в диапазон ветви Если не входит. Пустая Попытка выделяет слово Попытка. Регрессии проверяют точные строку, offset и length для RU/EN, вложенных и однострочных случаев и после изменения заголовка/тела. Полный корпус LS, препроцессор и recovery не сертифицированы; полная эквивалентность не заявляется.

## Неправильно

```bsl
Если СуммаДокумента > Предел Тогда
	
КонецЕсли;
```

## Правильно

```bsl
Если СуммаДокумента > Предел Тогда
	ВыполнитьДействие(СуммаДокумента);
КонецЕсли;
```
