# Пустой блок кода

Проверяет, что блоки кода условий и циклов не пусты. Пустой блок — признак забытой реализации или удалённого содержимого: блок следует наполнить или удалить.

Не проверяются: тела методов (см. проверку «Пустой метод»), блоки «Исключение» (см. проверку «Пустое исключение») и файловый блок модуля.

Параметр **Считать комментарии кодом** (по умолчанию выключен): блок, содержащий комментарии, пустым не считается.

## Неправильно

```bsl
Если СуммаДокумента > Предел Тогда
	
КонецЕсли;
```

## Правильно

```bsl
Если СуммаДокумента > Предел Тогда
	ВыполнитьДействие(СуммаДокумента);
КонецЕсли;
```
