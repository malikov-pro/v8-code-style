# Пустой блок кода

Проверяет, что блоки кода условий, циклов и Попытки не пусты. Пустой блок — признак забытой реализации или удалённого содержимого: блок следует наполнить или удалить.

Не проверяются: тела методов (см. проверку «Пустой метод»), блоки «Исключение» (см. проверку «Пустое исключение») и файловый блок модуля.

Параметр **Считать комментарии кодом** (`commentAsCode`, по умолчанию false): комментарий должен находиться в проверяемой секции. Комментарий в другой ветви или Исключении не заполняет пустой блок; похожий текст внутри строкового литерала не считается комментарием. Пустая Попытка выделяет ключевое слово Попытка. Прежние якоря условий и циклов отличаются от диапазонов всей строки терминалов LS; точная эквивалентность позиций не заявляется.

## Неправильно

```bsl
Если СуммаДокумента > Предел Тогда
	
КонецЕсли;
```

## Правильно

```bsl
Если СуммаДокумента > Предел Тогда
	ВыполнитьДействие(СуммаДокумента);
КонецЕсли;
```
