# Локализуемая строка начинается или заканчивается непечатаемым символом

Проверяет, что текст сообщения каждой языковой записи локализуемой строки, переданной в функцию `НСтр` (`NStr`), не начинается и не заканчивается непечатаемым символом (пробел, табуляция, перенос строки).

Неязыковые символы по краям сообщения нужно выносить в отдельные строковые литералы, складываемые с локализуемой строкой: переводчик не видит всего контекста, и краевой пробел или перенос легко теряется или искажается при переводе (стандарт 761).

## Неправильно

```bsl
// Перенос строки внутри текста сообщения.
Текст = НСтр("ru = 'Не удалось сохранить файл по причине:
|'") + Подробности;

// Пробел в конце текста сообщения.
Текст = НСтр("ru='Текст сообщения '");

// Пробел в начале текста одной из языковых записей.
Текст = НСтр("ru='Текст сообщения', en=' Message text'");
```

## Правильно

```bsl
// Неязыковые символы — отдельные строковые литералы.
Текст = НСтр("ru = 'Не удалось сохранить файл по причине:'")
	+ Символы.ПС + Подробности;

Текст = НСтр("ru='Текст сообщения'");

Текст = НСтр("ru='Текст сообщения', en='Message text'");
```

Записи, не соответствующие синтаксису локализованной строки (значение в двойных кавычках или без кавычек, отсутствие кода языка, незакрытый текст, разделитель без следующей записи), помечает проверка **Синтаксис локализованной строки функции НСтр**; первый параметр — не строковый литерал — помечает проверка **Формат строкового литерала НСтр**. Одно замечание на строковый литерал.
