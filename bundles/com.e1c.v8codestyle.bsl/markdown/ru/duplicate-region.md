# Повторяющиеся разделы модуля

Каждая область верхнего уровня должна встречаться в модуле один раз. Проверка
выдаёт одно замечание на первой открывающей директиве каждой группы повторов,
в том числе для нестандартных имён. Вложенные области и области внутри методов
не проверяются.

Стандартные русские и английские имена (ПрограммныйИнтерфейс, СлужебныйПрограммныйИнтерфейс,
СлужебныеПроцедурыИФункции, ОписаниеПеременных, Инициализация и разделы обработчиков)
сопоставляются без учёта регистра. Нестандартные имена сравниваются точно,
с учётом регистра, как в pinned BSL LS. УстаревшиеПроцедурыИФункции не является
стандартным псевдонимом этой проверки; суффиксы областей таблиц не переводятся.

Включена по умолчанию, CODE_STYLE / TRIVIAL. Параметров и автоисправления нет:
для объединения областей нужно решить, куда переносить их содержимое.
Связанные позиции остальных повторов из LS в этой версии не перенесены.

Пока проверка включена, `module-structure-top-region` передаёт ей дубли верхнего
уровня, но продолжает проверять вложенные дубли, порядок и расположение областей.
При отключении новой проверки прежний аудит дублей восстанавливается, если
в старой проверке включён `checkDuplicates`. Настройки пользователя не меняются.
