# Аудит запуска внешних приложений

Opt-in проверка SECURITY/MAJOR глобальных и member-вызовов по pinned
BSL Language Server ExternalAppStarting. Выключена по умолчанию. Выделяет имя
метода, не аргументы и не владельца. Быстрого исправления нет.

`userPatternString` — Java regex, полное совпадение имени без учёта регистра
RU/EN. По умолчанию включает КомандаСистемы/ЗапуститьСистему/ЗапуститьПриложение,
НачатьЗапускПриложения/ЗапуститьПриложениеАсинх и английские имена, а также
ЗапуститьПрограмму, ОткрытьПроводник и ОткрытьФайл.

`checkGotoUrl` по умолчанию false. При true к пользовательскому regex добавляются
альтернативы ПерейтиПоНавигационнойСсылке, GotoURL и ОткрытьНавигационнуюСсылку
точно как в LS. Пустой regex не совпадает с именами, пока не включена навигация.
Ошибочный итоговый regex даёт WARNING в журнале и пропускает проверку на этом
проходе; автоматической подмены пользовательского regex дефолтом нет.

Владелец намеренно НЕ определяется: и
`ФайловаяСистема.ЗапуститьПрограмму(...)`, и
`МойМодуль.ЗапуститьПрограмму(...)` попадают в аудит. Возможны ложные срабатывания
на одноимённых пользовательских методах. Замечание предлагает проверить вызов,
а не доказывает запуск приложения или уязвимость. При необходимости настройте
regex под проект. Строки, комментарии и обращения без вызова исключены.
Проверяются методы и тело модуля. Другие аудиты и use-non-recommended-method
независимы; автодедупа и изменения их настроек нет. Код1С не исполняется.

Источник: [BSL Language Server: ExternalAppStarting](https://1c-syntax.github.io/bsl-language-server/diagnostics/ExternalAppStarting/).
