# Категория ошибки недоступна при заданной совместимости

Узкий остаток pinned LS UnavailableMemberCall: разрешённые платформенные значения КатегорияОшибки, появившиеся позже режима совместимости конфигурации. По умолчанию включена, MAJOR/ERROR, без параметров.

Версии взяты из записей КатегорияОшибки pinned LS builtin-platform-types.json, commit 33a1400681e342ad4bd12281dcee8c7db781ee3d, а не угаданы по имени. Runtime проекта EDT выбирает модель для разрешения ссылки. Неразрешённые значения, неизвестные получатели и одноимённые поля Structure пропускаются; штатные замечания неизвестных имён, глобальных вызовов и конструкторов не дублируются.

Это не универсальный сервис версий членов/типов: другие перечисления, методы, свойства, конструкторы, данные HBK и явный targetVersion LS вне этого этапа. Полная эквивалентность LS не сертифицирована. Автоисправление и связанные позиции не добавлены.
