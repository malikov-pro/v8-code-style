# Нулевые поля табличного документа

Не устанавливайте нулевые поля (ПоляСлева/Справа/Сверху/Снизу) у табличного документа: при печати с нулевыми полями содержимое документа обрезается по краям листа. Задавайте достаточные поля с учётом непечатаемой области принтера или оставляйте стандартные поля (статья 548 стандарта, формирование печатных форм).

Проверка просматривает весь текст модуля, включая комментарии и строковые литералы, без учёта регистра, и помечает каждое присваивание нуля свойствам полей табличного документа (русские и английские имена свойств):

- `.ПолеСлева = 0` (`.LeftMargin = 0`), `.ПолеСправа = 0` (`.RightMargin = 0`)
- `.ПолеСверху = 0` (`.TopMargin = 0`), `.ПолеСнизу = 0` (`.BottomMargin = 0`)

В отличие от точного поиска подстроки в исходном алгоритме АПК допускаются пробелы вокруг знака присваивания. Как и в алгоритме АПК, присваивание не отличимо от сравнения, поэтому выражение вида `Если ТД.ПолеСлева = 0` также помечается.

## Неправильно

```bsl
Процедура ПечатьДокумента(ТабДок, Данные)

	// содержимое будет обрезано при печати
	ТабДок.ПолеСлева = 0;
	ТабДок.ПолеСверху = 0;

КонецПроцедуры
```

## Правильно

```bsl
Процедура ПечатьДокумента(ТабДок, Данные)

	ТабДок.ПолеСлева = 10;   // мм
	ТабДок.ПолеСправа = 10;  // мм
	ТабДок.ПолеСверху = 20;  // мм
	ТабДок.ПолеСнизу = 20;   // мм

КонецПроцедуры
```
