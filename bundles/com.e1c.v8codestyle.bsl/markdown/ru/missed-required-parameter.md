# Пустой обязательный аргумент

Дополняет штатную проверку числа аргументов EDT. Находит явно пустые позиции вроде `Расчёт(, 2)`, когда вызов разрешается в пользовательскую функцию/процедуру, а соответствующий параметр не имеет значения по умолчанию. Пустые необязательные аргументы и явно переданное Неопределено не являются нарушением. Неразрешённые и неоднозначные методы пропускаются; совпадение имени не доказывает сигнатуру. Одно замечание перечисляет пустые обязательные параметры в порядке объявления.

Включена по умолчанию, MAJOR/ERROR, без параметров и автоматического исправления. Частичный перенос LS MissedRequiredParameter: отсутствующие конечные аргументы и конструкторы/платформенные сигнатуры оставлены штатной валидации и отдельно не отмечаются. Вызов с недостаточным числом аргументов целиком пропускается во избежание дубля штатной ошибки, даже если содержит пустую позицию. Связанные диапазоны не добавляются. Изменение межмодульной сигнатуры должно пересчитывать вызывающий модуль без изменения его исходника.
