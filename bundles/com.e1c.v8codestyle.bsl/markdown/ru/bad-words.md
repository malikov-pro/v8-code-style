# Запрещённые слова

Проверяет, что в тексте модуля не встречаются запрещённые слова. Список слов задаётся регулярным выражением в параметре **badWords**; поиск выполняется без учёта регистра.

Проверка сканирует **каждую строку текста модуля**, включая комментарии и строковые литералы; каждое вхождение (в том числе внутри идентификаторов) помечается отдельным замечанием на позиции вхождения в строке.

Список по умолчанию пустой, проверка **выключена по умолчанию**: включите её в настройках проверок и настройте список слов под стандарты вашей команды или проекта.

Пример параметра: `лотус|шмотус` — два слова через `|`; поддерживается полный синтаксис регулярных выражений.

## Источники

Перенос диагностики BSL Language Server `BadWords` (в LS диагностика тоже выключена по умолчанию и имеет пустой список слов).

Отличие от LS: отдельный параметр «искать в комментариях» не переносился — перенос всегда сканирует весь текст модуля, что соответствует поведению LS по умолчанию.

Quick fix не предусмотрен: переформулировка текста — решение пользователя.
