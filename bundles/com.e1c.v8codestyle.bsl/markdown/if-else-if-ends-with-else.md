# If/ElsIf chain without Else

An If chain with at least one ElsIf must have an Else branch. A simple If needs no Else. An empty Else is accepted; nested Else branches do not satisfy the enclosing chain. Methods and module-level code are checked, highlighting EndIf. Enabled by default, MAJOR/WARNING, no parameters or quick fix.
