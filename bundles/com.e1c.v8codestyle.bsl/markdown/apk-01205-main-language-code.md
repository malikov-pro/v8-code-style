# Main language code is obtained via Metadata.MainLanguage

When the Standard Subsystems Library (SSL) is used, the main language code shall be obtained by calling the **MainLanguageCode** function of the **Common** (ОбщегоНазначения) common module, not by accessing `Metadata.MainLanguage` (e.g. `NStr("ru = '...'", Metadata.MainLanguage.LanguageCode)`).

The only allowed place is the `MainLanguageCode` function of the `Common` common module of the SSL itself.

## Noncompliant Code Example

```bsl
Comment = NStr("ru = 'Комментарий к проводке'", Metadata.MainLanguage.LanguageCode);
```

## Compliant Solution

```bsl
Comment = NStr("ru = 'Комментарий к проводке'", Common.MainLanguageCode());
```
