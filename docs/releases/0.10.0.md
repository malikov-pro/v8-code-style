# 0.10.0 — кандидат к выпуску

Версия ещё не опубликована. Состав сравнивается с тегом `0.9.0`.

## Требования и обновление

- Поддерживается **EDT 2026.2.2 / Java 25 / Linux GTK x86_64**.
  Совместимость с EDT 2026.1 и Java 17 прекращена.
- Форк обновляет комплектный v8-code-style на месте: используются те же IU.
  Перед обновлением сохраните работу и настройки проверок. Откат требует
  восстановления комплектной версии из дистрибутива EDT.
- Для живой EDT используйте полную Java 25 с JavaFX и jshell: неполная JVM
  может нарушить работу карточек замечаний сторонних компонентов EDT.
- На некоторых обновлениях наблюдалось `Unknown check id` при первом запуске.
  Если новые проверки недоступны, сохраните журнал и перезапустите EDT;
  затем выполните полную проверку проекта. Повторный запуск — обходной путь,
  а не исправление платформенного дефекта. Если ошибка остаётся, сохраните
  журнал для диагностики; отсутствие маркеров не означает успешную проверку.

## Проверки кода и запросов

- Добавлены CFG-проверки `all-function-path-must-have-return` и
  `unreachable-code`. Первая проверяет пути функции с учётом двух параметров
  LS; вторая дополняет штатную детекцию участками после Break/Continue/Goto,
  без дублирования штатных Return/Raise. Переходы по меткам моделируются,
  прежний пропуск целого метода с Goto отменён.
- `use-goto-operator` имеет важность **BLOCKER по умолчанию**. Ручная важность
  пользователя не перезаписывается.
- Расширены проверки вызовов, пустых обязательных аргументов, категорий ошибок,
  типов Boolean и возвращаемых примитивов, сигнатур обработчиков форм и событий.
- Уточнены семантика и диапазоны проверок метрик, вложенности, параметров,
  пустых блоков, повторных выражений/условий, комментариев, временного хранилища
  и таймаутов. Сравнение выражений не меняет регистр и пробелы внутри строк.
- Дополнены проверки запросов: JOIN/WHERE, составные ссылки с учётом типов,
  UNION, TOP и порядок, контракты виртуальных таблиц; проверены мосты из BSL,
  СКД и динамического списка в пределах сценариев соответствующих проверок.
- Дополнены проверки метаданных: подписки, регламентные задания, обработчики
  HTTP/веб-сервисов, устаревшие свойства платформы и диаграмм. Штатные ошибки
  EDT не подменяются переносимыми проверками.

## Новые opt-in аудиты безопасности

По умолчанию выключены, тип **SECURITY**, важность **MAJOR**:

- `set-privileged-mode` — использование привилегированного режима;
- `temp-files-dir` — использование каталога временных файлов;
- `use-system-information` — получение информации о системе;
- `internet-access` — доступ к интернет-ресурсам;
- `file-system-access` — доступ к файловой системе;
- `external-app-starting` — вызовы запуска приложений.

Это точки аудита, а не доказательство уязвимости. Включайте и настраивайте их
под проект. `file-system-access` и `temp-files-dir` независимы: пересечения
намеренно сохранены, автоматического выключения или дедупликации нет.
`internet-access` не заменяет проверку таймаутов.

`external-app-starting` проверяет глобальные и member-вызовы **по имени**, без
определения владельца. Одноимённый пользовательский метод тоже может получить
замечание. `userPatternString` задаёт regex полного имени без учёта регистра;
`checkGotoUrl=false` по умолчанию. Ошибочный regex даёт WARNING и пропускает
проверку на этом проходе, без скрытой подмены дефолтным шаблоном. Автоисправления
нет; аудит не исполняет BSL-код.

## Сборка и приёмка

- Канонический вход — `bash compile.sh`, Maven 3.9.9 и JDK 25.
- Платформа загружается из публичных источников 1С/Eclipse/Orbit. Приватный
  архив EDT и secret `EDT_P2_ARCHIVE_URL` не нужны. Корневые IU имеют точные
  версии, metadata всех четырёх источников проверяются по SHA-256 до Maven.
  Изменившийся upstream требует пересмотра lock, а не автоматического принятия.
- Для тестовой среды явно подключены SCR, SWT SVG и EventAdmin. Проверки и
  assertions ради разрешения зависимостей не ослаблялись.
- Результаты окончательного RC и установленный квалификатор фиксируются в
  отчёте приёмки отдельно. Предыдущий полный гейт версии 0.9.0-SNAPSHOT не
  выдаётся за гейт версии 0.10.0.

## Что не вошло

`ExcessiveAutoTestCheck`, `UsageWriteLogEvent`, `PrivilegedModuleMethodCall` и
`OrdinaryAppSupport` отложены. Новая функциональность заморожена на время выпуска.
